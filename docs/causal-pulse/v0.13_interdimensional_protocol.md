# v0.13 维度隔离协议（伤官见官与干支维轴）

> **单一事实来源**：`qiazhi_bazi/backend/app/plugins/base_physics/manifests/l1_physics_manifest.json` 与 `StemBranchCouplingEngine` 实现须与本页一致。调整 `MANGPAI_ETA_DIMENSIONAL_CRUSH`、`CONDUCTIVITY_DECAY_RATE` 等系数时，**须先更新本页与 manifest**，再改代码。

## 1. 裁决共识（伤官见官）

- **问题**：天干「伤官」与地支藏干中的「官」若在无通根、无冲刑介质下被强行拉成高 Abs 损耗，易叙事滥用。
- **共识**：跨柱 **干维 ↔ 支维** 交互默认 **不传导**（`c_phys = 0`），除非存在 **同柱（1.0）**、**通根（0.8）** 或 **冲刑激活介质（0.5）** 之一。
- **因果脉冲**：当有效传导过低且损耗被压灭时，写入 `[CAUSAL_SHIELDED]: … 无功干扰`（见 `op_interdimensional.shield_log_line`）。

## 2. 传导率四档（与实现对齐）

| 档位 | 数值 | 判定 |
|------|------|------|
| 同柱 | **1.0** | stem 与 branch 节点同属 `year|month|day|hour` 之一 |
| 通根 | **0.8** | 该天干字面出现在四柱任一支的 **藏干表**（`BRANCH_HIDDEN_STEMS`）中 |
| 冲刑激活 | **0.5** | 目标支所在柱出现在 **当前交互点以外** 的 `clash` / `punish` 冲突边的涉及柱位中 |
| 隔离 | **0.0** | 以上皆否 |

**后处理（在 base 上）**：

1. 柱距衰减：`base *= CONDUCTIVITY_DECAY_RATE ** max(0, pillar_distance - 1)`（相邻柱不衰减）。
2. 屏障弱化：`base *= max(0, 1 - INTERDIMENSIONAL_BARRIER_STRENGTH × 0.35 × (1 - min(1, base)))`。
3. 截断到 `[0, 1]`。

**人工传导（裁决人滑块）**：

`effective = clamp01(c_phys + (1 - c_phys) × min(1, INTERDIMENSIONAL_CONDUCTIVITY / 2))`

当 `INTERDIMENSIONAL_SHIELD_ENABLE < 0.5` 时，**关闭维度屏蔽**，`c_phys = effective = 1`（不做跨维衰减）。

## 3. 盖头截脚（垂直损耗）

同柱天干五行与地支 **本气** 五行相克（干克支或支克干）时，生成 `interdimensional.vertical_crush` 步骤：

`abs_loss = round(raw_energy(pillar) × MANGPAI_ETA_DIMENSIONAL_CRUSH × 0.12, 4)`

由 `STEM_BRANCH_VERTICAL_CRUSH_ENABLE` 开关控制。

## 4. 通根谐振（仅冲局 abs_gain）

当 **通根** 且 **支本气透干**（本气天干在四柱天干中出现）且交互为 **clash** 时：

`abs_gain' = round(abs_gain × MANGPAI_ROOT_RESONANCE, 4)`（`MANGPAI_ROOT_RESONANCE` clamp 到 `[0,3]`）

由 `STEM_BRANCH_ROOT_RESONANCE_ENABLE` 控制。

## 5. 虚实比存证

`physics_tensor.meta.solid_ghost_ratio` 由混维步骤的平均 `conductivity_effective`、`GHOST_ENERGY_DAMPING` 与屏蔽条数合成，供终审证书展示 **Solid / Ghost** 比例。
