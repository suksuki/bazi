# EDR-050：A-21 / A-22 量子隧道测试例（从强↔从弱断裂式坍缩）

**状态**：设计占位，待第二梯队迁库后实现。  
**审计要求**：第二梯队入库后，准备「量子隧道测试例」——原局 A-21（从强）在强克泄扰动下 5D 是否发生向 A-22（从弱）流形的断裂式坍缩，并触发高压判词。

---

## 1. 物理场景

- **原局**：L1 判定为 A-21（从强格），满局印比、无/极微克泄。
- **动态扰动**：大运或流年引入强财/官杀（例如强财坏印、官杀克身），使十神比例与根气发生剧变。
- **观测**：同一命例在「原局 vs 扰动后」的 5D 坐标是否从 A-21 质心邻域跃迁到 A-22 质心邻域（马氏距离或欧氏距离发生阶跃）。
- **判词要求**：RAG/判词引擎在检测到此类位移时，应输出高压警告类表述，例如「**大厦将倾，弃守为上**」。

---

## 2. 实现要点（待开发）

1. **样本**：从 518k 或已迁库的 `pattern_points` 中选取 L1 纯 A-21 样本（或构造满足从强条件的八字）。
2. **扰动**：用现有大运/流年十神重算逻辑，生成「原局 + 某大运/流年」的 ten_gods；或构造「强财坏印」等极端配置的合成 ten_gods。
3. **5D 位移**：对原局与扰动后分别做 V4 矩阵投影得到 5D 点，计算到 A-21 / A-22 质心的距离；若扰动后到 A-22 更近且到 A-21 明显变远，记为一次「坍缩」。
4. **判词联调**：在动态流形/判词链路中，当检测到格局置信度从 A-21 主导变为 A-22 主导时，注入上述高压警告句（可配置于 RAG 或 HKB 规则）。

---

## 3. 验收标准

- 至少 1 个可复现案例：原局 A-21 → 扰动后 5D 更近 A-22，且判词含「大厦将倾，弃守为上」或等效高压表述。
- 文档/脚本位置：本 EDR 或 `audit_logs/` 下保留测试例输入（八字/大运/流年）与期望输出摘要，便于审计复现。
