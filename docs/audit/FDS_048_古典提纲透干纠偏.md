# 第 048 号纠偏：FDS 海选算法「法理重构」— 提纲 + 透干

**审计师签发**：此前海选仅用「月令静态藏干」导致 388k 级数据泛滥；古典成格逻辑为**提纲、透干、会合**，月令所藏若不透出天干则力量潜伏，不能轻易论格。

---

## 一、古典格局物理准则（终极判准）

### 1. 官杀印食伤：以「透干」与「纯度」为纲

| 格局 | 古典法理硬核约束 (L1) | 5D 张量特征要求（参考） |
|------|------------------------|--------------------------|
| A-01 正官格 | 月令正官且**天干透出**（非伤官损克） | O≥1.5, S≤0.5 |
| A-02 七杀格 | 月令七杀且**天干透出** | S≥1.8 |
| A-05 枭神格 | 月令偏印且**天干透出**，且命局见食神（夺之势） | R≥1.5, E 偏移 |
| A-06 食神格 | 月令食神且**天干透出**，未见枭神 | E_output≥1.2, M 趋正 |
| A-07 伤官格 | 月令伤官且**天干透出** | E_output≥1.8, O≤−0.8 |
| A-08 正印格 | 月令正印且**天干透出**，不被财星坏印 | R≥1.5, O≥1.2 |

### 2. 财格：以「能量分位」为纲

- **A-03 偏财格**：月令偏财司权且**透干**，身财两停 `M_axis > 1.2`。
- **A-04 正财格**：月令正财司权且**透干**，身财两停 `M_axis > 1.2`。

### 3. 禄刃：以「地支位能」为纲

- **A-09 建禄格**：月支为日干**临官**之地。
- **A-10 阳刃格**：月支为日干**帝旺**之地；阳刃通常指五阳干（甲丙戊庚壬）。

## 二、实现要点

- **核心模块**：`core/classical_tougan.py`  
  - `get_month_main_stem(branch)` → 月支本气天干  
  - `get_ten_god_code(dm, target_stem)` → 十神 manifest 代码  
  - `get_twelve_stage(dm, branch)` → 十二长生（临官/帝旺）  
  - `enrich_case_with_classical_l1(case)` → 注入 `month_main_god`, `stems_revealed`, `month_stage`  
  - `is_classical_pattern_achieved(case, pattern_id)` → 提纲+透干/禄刃 硬约束  

- **海选入口**：`scripts/build_a01_full_index.py`  
  - A-01～A-10 默认启用 `use_048_tougan=True`，先过 `is_classical_pattern_achieved` 再过 JsonLogic。  
  - A-11～A-13 不强制透干，仍由 manifest pipeline 负责。  

- **数据要求**：518k 每条须含 `bazi`（年/月/日/时 干支）。若缺 bazi，该条不通过古典 L1，A-01～A-10 不计数。

## 三、数据清洗与自检红线

1. **执行清空**：重刷前需清空 DuckDB 格局点表（或整库重建），再由迁移脚本写入新 npz。  
   - 清空方式：`DELETE FROM pattern_points` 或按需 `DROP TABLE pattern_points` 后重建表。  

2. **重刷 518k**：以「月令藏干透干」为硬指标重新扫描：  
   - `python3 scripts/fds_pattern_scanner.py --target A-01` … A-10（及 A-11～A-13）。  
   - 或批量执行 `scripts/run_a11_a12_a13_scan_and_migrate.py` 后，对 A-01～A-10 逐格运行 scanner。  

3. **统计自检**：若格局 **A-01 至 A-10** 的总样本数超过 518k 的 **20%**（即 > 103,680），则认定存在「泛滥误差」，**审计不通过**，须进一步收紧 L1 或检查数据与透干逻辑。
