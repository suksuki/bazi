# FDS 全息知识库 (HKB) 自动化生成 SOP v1.0

## 1. 核心定义
HKB 是格局 Manifest 的语义扩展层，旨在通过 5D 张量分布自动生成可解释的命理知识。

## 2. 触发条件
- 格局已完成 Step 2.2 子格局晋升协议。
- 注册表文件 `registry/holographic_pattern/{ID}.json` 已包含有效的 Benchmarks 和 Centroids。

## 3. 执行流程
### Step 1: 物理特征提取
- 从 Registry 中读取全量样本的 5D 质心向量 $\vec{C}$。
- 计算各子格局（S1, S2...）在 5D 空间中的主导维度（如 A01-S1 的主导轴为 $E$）。

### Step 2: 语义映射 (Semantic Mapping)
- **能量轴 (E)**: 映射为“身强/身弱”、“生命力能级”。
- **秩序轴 (O)**: 映射为“社会地位”、“克制力”、“法律边界”。
- **财富轴 (M)**: 映射为“资源拥有度”、“物质丰盈度”。
- **压力轴 (S)**: 映射为“环境应力”、“危机感”。
- **智慧轴 (R)**: 映射为“逻辑深度”、“精神高度”。

### Step 3: 知识封卷
- 产出 `knowledge/holographic_pattern/{ID}_kb.json`。
- 包含：物理综述、古典对齐判词、奇点风险提示。

## 4. 验收标准
- 知识库必须包含至少一个 5D 向量锚点用于相似度匹配。
- 严禁硬编码描述，所有结论必须基于张量数值动态生成。
