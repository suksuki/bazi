# 📜 盲派物理化全景知识库 (BLIND_SCHOOL_V1)

## 0. 核心哲学：效率优先 (Efficiency over Balance)
- **旺衰派**关注“我（日主）适不舒服”；**盲派**关注“我（日主）能不能拿到东西”。
- 在 0.13 实验室中，所有盲派逻辑必须建立在 **L1 物理 Abs（能量绝对值）** 之上。

---

## 1. 空间主权：家里与家外 (Spatial Sovereignty)
这是盲派的“雷达地图”，决定了能量是“我的”还是“社会的”。

### 1.1 阵营划分
| 空间划分 | 对应柱位 | 语义定义 | 物理建模逻辑 |
| :--- | :--- | :--- | :--- |
| **家里 (INTERNAL)** | **日柱、时柱** | 私人领域、配偶子女、我的身体、我的存量资产。 | **能量的归宿端。** 所有做功的终点应指向此处。 |
| **家外 (EXTERNAL)** | **年柱、月柱** | 社会环境、职场、官府、他人财富、公共资源。 | **能量的供应源。** 是我们要捕获的目标区。 |

> **[核心策略]**：
> - **取财官**：用“家里”的体（手脚）去合/克/冲“家外”的用（财富）。**即：外财入家。**
> - **丢财官**：家里的财被家外合走，或家外的暴力能量（劫财/杀）冲破家门。**即：资产流失。**

## 2. 功能逻辑：体与用 (Body vs. Use)
体用决定了谁是“猎人”，谁是“猎物”。

- **体 (BODY)**：我的本钱、工具。
  - *包含*：日主、印星、禄神、比劫（我的人脉与力气）。
- **用 (USE)**：我的目标、猎物。
  - *包含*：财星（钱财、女人）、官杀（地位、名誉、权力）。
- **中立/桥梁 (BRIDGE)**：食伤。既可以是“体”（我的才华），也可以是“用”（财富的来源）。

---

## 3. 动力学：做功手段与效率 ($\eta$)
盲派不看旺衰平衡，只看“工具”好不好使。

| 交互手段 (L1) | 盲派物理语义 | 转换效率 ($\eta$) | 风险系数 ($Tax$) |
| :--- | :--- | :--- | :--- |
| **合 (Combine)** | 闭锁与捕获。合住财官即为得到。 | 1.0 (最高) | 低（除非被反向合走） |
| **冲 (Clash)** | 暴力获取。如冲开墓库，瞬间释放海量能量。 | 0.8 | 高（主动荡、位移） |
| **穿/害 (Pierce)** | 毁灭性拦截，精准且带损伤。主“快、狠”。 | 0.9 | 极高 (损伤 BODY) |
| **墓 (Grave)** | 能量保险柜。**不开不发**。需用冲/刑开启。 | 动态 | 中（不发则为闭锁） |

## 4. 盲派物理化判定公式
基于你 214.55 的案例，我们要让 LLM 遵循这个硬核逻辑：

$$Net\_Effect = \sum (Abs_{source} \times \eta \times Climate\_Modifier) - Backfire\_Risk$$

- **身强无依 (Energy Congestion)**：`Self_Abs > 15` 且 `Work_Vectors` 为空。
- **反噬 (Backfire)**：当“用”的能量远大于“体”，或者做功路径被岁运截断（如子午冲）。
