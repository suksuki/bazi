# SOP V7.5 格局迁移典型判词对照表

**版本**: V7.5  
**用途**: 供全息页 LLM 判词与跨年份连续观测时，核对不同迁移态下的叙事精度。  
**状态机**: original（原局成格）| formed_by_transport（岁运成格）| broken_year（岁运破格）

---

## 1. 状态与 verdict_type 对应

| 状态 state | verdict_type | 判词叙事要点 |
|------------|--------------|--------------|
| original | 成格 | 古典法理成立，与命局结构相符；可结合大运流年论吉凶。 |
| formed_by_transport | 岁运成格 | 须体现「此岁运交汇，化气成象」或等价表述；格局由岁运催化成立，宜结合流年大运论成败。 |
| broken_year | 岁运破格 | 须提示原局成格但当前岁运引动破格（如从格见比劫），宜慎防逆势、重点参考 5D 流形。 |

---

## 2. 典型迁移案例与预期判词方向

### 2.1 岁运成格：杀印相生 → 阳刃/建禄（寅午戌合火）

- **能量相**: 大运/流年地支凑齐寅午戌三合火，全局火元素权重暴涨，原局「杀印相生」在合成场中坍缩为阳刃/建禄特征。
- **系统输出**: state=formed_by_transport, verdict_type=岁运成格。
- **判词预期**: 出现「岁运交汇」「化气成象」「由……重组为……」等表述；建议行事宜更显刚毅、顺势而为。

### 2.2 岁运成格：伤官格 → 金水伤官专旺/从儿（申子辰三合水）

- **案例**: 庚金日主生于子月（伤官格），大运/流年见申、辰。
- **能量相**: 申子辰三合水局，合成场水势极旺。
- **系统输出**: 伤官格 + 从儿/专旺（岁运成格）。
- **判词预期**: 从「小聪明/技术职」跃迁为「声势浩大、席卷行业」的统帅态；叙事上体现由单格晋升为专旺/从儿（岁运成格）。

### 2.3 岁运破格：从格见比劫夺财

- **风险相**: 从格（A-31～A-35）在合成场中见比劫夺财，integrity 自动下调并标为岁运破格。
- **系统输出**: state=broken_year, verdict_type=岁运破格。
- **判词预期**: 明确提示逆势与慎防；建议重点参考 5D 流形与物理偏移，勿仅依古典名分做决策。

---

## 3. 地域对 integrity 的微调（SOP V7.5 补充）

- **得地**: 格局五行与地域五行一致 → integrity += 0.05（封顶 1.0）。系数来自 `config/classical_registry.json` → `integrity_geo.de_di_bonus`。
- **失地**: 格局五行被地域克制 → integrity -= 0.10。系数来自 `integrity_geo.shi_di_penalty`。
- **判词**: 当前版本不强制在判词中单独写「得地/失地」，但 integrity 已参与排序与格成列表展示；若后续需在叙事中显式体现地域，可在此表增加「得地/失地」典型句模板。

---

## 4. 核对清单（跨年份连续观测时）

1. **标签跳变**: 古典格局观测区是否随年份出现 **[岁运成格]** / **[岁运破格]** 标签。
2. **判词转折**: LLM 判词是否在 formed_by_transport / broken_year 时出现「岁运交汇」「化气成象」「慎防逆势」等对应表述。
3. **pattern_change_trigger**: 全息页是否在存在岁运触发时展示「SOP V7.5 岁运引发」提示，且判词 prompt 已注入对应 trigger 文案。

---

## 5. SOP V7.7 弹性定性补充说明

- **定性优先**：自 V7.7 起，古典格局一旦满足结构/逻辑（L1+硬规则）即判为格成，匹配度统一视为 100%，不再以能量阈值决定是否成格。
- **成色分级**：能量仅决定成色（`energy_tier` = high/mid/low），用于区分「格成极真、富贵自天来」（high）与「格局虽成，然根基尚浅，需步步为营」（low）等叙事口径。
- **结构救应**：若存在成败救应（如正官见财、七杀见印、伤官见财/印），在 `structural_rescue` 中标记为 True，并在法理排序中加权，优先进入主权格局叙事。
- **瞬时态**：由岁运补齐而成立者标记为 `ephemeral=True`，UI 与判词中应体现为「岁运成格」「阶段性态势」，而非终身定论。
