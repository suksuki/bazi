# V60 Active Product Delivery

This is the single living delivery list for the current local V60 product.
It records executable work, not speculative phases. Completed history remains
in `docs/CHANGELOG.md`.

## Product Direction

V60 is a Mingli-centered Life Intelligence product. Mingli Calculation is the
core brain and truth-facing product; Abu Dream World is the priority game
breakthrough. Lab improves Mingli through versioned admission, Abu Says is the
native expression of the current Reading, and Theater is a relatively
independent directing and media-production studio.

Every iteration must preserve:

1. real, versioned data ownership;
2. one canonical Case, graph, world clock and event lineage;
3. refresh and process-restart recovery;
4. explicit separation of fact, inference, hypothesis, simulation and visual
   expression;
5. a visible product improvement before generalized infrastructure work.

## Current Playable Baseline

```text
login
-> persistent LifeTree encounter
-> observe two leaves and one branch
-> question flower
-> independent AnswerSeals
-> world settlement
-> fruit reveal and reconciliation
-> return encounter on the same world line
```

The same snapshot feeds Dream, Mingli Calculation, Abu, Theater and Lab. The
current implementation is desktop-first; mobile remains a guardrail until the
desktop composition is stable.
