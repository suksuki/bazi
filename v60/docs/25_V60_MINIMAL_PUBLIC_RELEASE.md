## 1. Owner 决策

V60 公开产品只保留：

```text
登录 / 私密档案
→ 原生命树与档案叶
→ 原命理枝与枝、叶、花、果
→ 确定性命盘与按主题断命
→ 阿布说
```

简化只发生在功能、入口和运行边界，不替换已经确认的产品 UI。完整 LAB 不进入
公开菜单或路由；其六柱粒子渲染、字幕与声音同步能力作为 Mingli 共享基础组件保留，
合成训练与蒸馏作为内部能力保留。

原叙事／游戏产品线已从 V60 物理移除，不再是“冻结等待恢复”的模块。

## 2. 公开体验

- 唯一页面入口是 `/experience`。
- 用户可切换已有私密档案或新建命盘。
- 生命树、档案叶、命理枝、枝叶花果生长动画、阿布与多多继续使用既有视觉语言。
- 点档案叶进入命理枝；点枝、叶、花、果直接打开对应断语与阿布说。
- “断命”和“阿布说”读取同一份已落库内容，不进行第二次命理计算。
- 阿布说使用本命四柱、当前大运和所选流年的六柱舞台。
- 白天舞台使用深色五行粒子、字形与正文，并在正文后方提供局部宣纸承托，避免
  中央高光降低可读性。
- 页面先显示本地确定性基础稿；Qwen 只按当前主题补充文字，完成后自动更新。
- 声音只在用户主动点击后生成，声音失败不阻塞文字。

## 3. 阿布说同步合同

专属 TTS 返回音频和句／分句 Cue。浏览器以 `HTMLAudioElement.currentTime` 为唯一
时钟，每一帧由同一时间确定：

1. 当前字幕；
2. 阿布播放／暂停状态；
3. 六柱中的活动柱位；
4. 对应粒子本体的呼吸、旋转与强调。

暂停、缓冲或拖动时，字幕和粒子跟随同一个音频时钟，不各自计时。只有明确出现的
年柱、月柱、日柱、时柱、大运或流年词才激活对应柱位。设备语音降级没有可靠 Cue，
因此只保留环境动画，不伪造逐句同步。

## 6. 服务端边界

- 注册：System、Identity、Mingli Cases、Mingli Stage、Focused Reading、
  Focused Speech、Public Experience。
- 条件注册：仅 Synthetic Mingli LAB。
- 后台不启动叙事／世界 worker。

  LifeCase 和生命树视觉投影。
