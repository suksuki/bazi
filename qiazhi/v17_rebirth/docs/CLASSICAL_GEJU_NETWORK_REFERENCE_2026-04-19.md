# 古典八字格局网络索引（V17 参考版）

更新时间：2026-04-19

目标：在不依赖现有旧系统命名映射的前提下，先建立一版可执行的古典格局资料基线，作为后续插件重构的依据。

## 一、核心结论先行

- 现有公开资料对“格局”有明显分歧，尤其在“正格/外格/变格/专旺/从格/化气格”边界上。
- 可以先采用“分层归一 + 来源溯源”策略，而不是一次性追求唯一真相。
- 目前可稳定拿到的公开分类线索（可直接用于规则设计）主要来自：  
  - 《三命通会》摘要类资料（以月令定格、十正格核心、内外格系统）  
  - 近现代教材型梳理（例如天机爻/国易堂/若干博文）  
  - 同时将“藏干主气/余气”与“月令主气取格”的原则作为共同底座。

### 3.2 二级：从化与特殊类（高优先判定）

## 四、从工程角度的落地建议（你后续可直接按这个开工）

1. **先不要强行实现 56/60 全部格局；先做“候选层”**  
   先把 `pattern_id -> family -> evidence_rules -> confidence` 落成。
2. **严格分离“命名类外格”和“计算类 L1 生克类插件”**  
   你的担忧里“太多冲突”本质来自混入了描述性外格与硬化学术判定。
3. **每个候选都保留来源标签**  
   `source: 本命|大运|流年|复合`，这样可直接支持大运/流年的动态评分。
4. **同一命局允许多格共存+混合评分**  
   比如 60% 某格 + 40% 另一个格，不做互斥二值判定。

## 五、当前资料中的冲突点（提前暴露，避免误用）

- “正格是不是十种？”：不同作者有不同口径（是否把建禄、羊刃并入正格或外格）。  
- “三命通会内外18格”是否完整：常有版本差异，若做全局统一，建议保留“名字字典”和“可计算定义”分离。  
- “命局是否必须以月令为绝对取格标准”：多数资料同意月令主导，但对旁干透出和组合互动规则差异较大（可通过动态分层化解）。

## 六、执行下一步（推荐）

1. 按上面的三级结构先建 `CLASSICAL_PATTERN_TAXONOMY` 数据表。  
2. 针对每一格只定义：
   - `min_evidence_signature`（最小可判据）
   - `strong_evidence_signature`（强证据）
   - `breakers`（破格条件）
   - `scope`（本命/大运/流年/复合）
   - `confidence_formula`（建议 0.0~1.0）  
3. 再把你现有 `classical` 插件替换为“证据产出器”，不在此阶段直接改十神基线数值。
