# V17 宏观象主题层设计与第一阶段实现

Date: 2026-04-26

## 1. 目标

宏观象是用户真正关心的解释层：财富、事业、感情、性格等主题，不应只由 LLM 临场发挥，也不应直接从单个十神粗暴映射。

第一阶段采用 `v17.macro.theme.v1`：

- 作为 L3 主题层。
- 只读 L0/L1/L2、体用裁决、格局候选、调候、盲派、象法和关系动力。
- 输出每个主题的激活度、置信度、风险、证据、机会、风险提示和 LLM 叙事焦点。
- 不改物理能量、不改体用候选、不自动写参数。

## 2. 第一批主题

- 财富：财星、食伤、体用顺忌、食伤生财/从财/财官等插件碰撞。
- 事业：官杀、印星、财官流通、官印结构、组织规则与运行压力。
- 感情：男女盘财官落点、合冲关系、家里家外、关系动力。
- 性格：比劫、食伤、印星、官杀的主导方式，输出表达、边界、防御和秩序感。

## 3. LLM 使用边界

LLM 可以把 `macro_theme` 写成自然语言，但必须遵守：

- 按主题激活度和置信度排序。
- 每个主题必须同时写条件、机会和风险。
- 不得把弱主题写成强结论。
- 不得改写系统返回的置信度、体用裁决或命理师本次覆盖前提。

## 4. 学习闭环

命理师反馈和案例后续应归入：

- `macro.wealth.calibration`
- `macro.career.calibration`
- `macro.relationship.calibration`
- `macro.personality.calibration`

这些学习素材只能进入审计候选和实验队列，不能直接改参数。
