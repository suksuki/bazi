# V17 八字门派架构对齐反馈（给分析师）

日期：2026-04-23

## 1. 目的

这份文档不是新增实现方案，而是对“八字主流门派/理论簇”做一次架构对齐反馈。

目标只有三个：

- 把分析师提出的门派划分，映射到 V17 当前已经落地的系统结构。
- 明确哪些分类值得采纳，哪些需要纠偏，避免把“门派”“专题”“算法视角”混成一层。
- 明确下一条真正值得新增的主轴，而不是继续横向扩张更多门派名词。

## 2. 当前结论

分析师这份分层思路整体是对的，但需要做一个关键纠偏：

- `格局派 / 扶抑派 / 调候派` 更适合归入 `子平 umbrella`，而不是和盲派并列为多个顶层平行门派。
- `十神流 / 新派 / 象法` 更接近“分析视角”或“专题推理策略”，不宜在当前阶段直接升级为完整顶层门派插件家族。
- 当前系统已经不是“没有门派层”，而是实际上已经形成了：
  - `ziping family`
  - `pattern_specializations`
  - `blind family`
  - `risk_matrix`
  - `shensha`
- 下一条最值得新增的，不是又一个门派标签，而是 `调候物理轴（climate / thermo field）`。

## 3. V17 当前真实分层

### 3.1 底层物理层

当前 V17 已经具备比较稳定的底层分层：

- `L0`：十神静态基础、根透桥、来源分解、基础能量结算
- `L1`：关系家族、几何命中、关系 runtime collector
- `Core`：做功图、运流场、authority、冲突与裁决
- `L2`：专题化解释与偏置层

也就是说，系统当前不是“某一个门派统治全局”，而是：

- 底层物理共享
- 上层多个专题并行解释
- 最终通过 authority 汇总

### 3.2 当前 L2 专题家族

从代码和协议实际状态看，当前已经存在这些专题家族：

| 家族 | 当前定位 | 主文件/协议 |
| --- | --- | --- |
| `ziping family` | 子平主裁决 | `ziping_family.py` |
| `pattern_specializations` | 古法格局/结构候选专题 | `classical.pattern.*` |
| `blind family` | 盲派独立专题 | `blind_school_core.py` / `blind_school_family.py` |
| `climate family` | 调候专题解释 | `climate_theme_core.py` / `classical.climate.*` |
| `xiangfa family` | 象法语义专题 | `xiangfa_theme_core.py` / `classical.xiangfa.*` |
| `risk_matrix` | 风险/逆转/冲突结构专题 | `l2.risk.risk_matrix` |
| `shensha` | 辅助标签层 | `shensha` |

所以从系统现状来说，我们已经进入了“多专题并行 + 主裁决汇总”的架构，而不是“单门派解释世界”。

## 4. 对分析师分类的采纳与纠偏

### 4.1 可以采纳的部分

分析师提出的总分层是有价值的：

- 第一层：正统理论主线
  - 子平
- 第二层：解释增强
  - 象法
  - 十神流
- 第三层：工程化/经验化
  - 盲派
  - 新派

这里最值得采纳的，不是门派名词本身，而是这条架构思想：

- 不同体系不一定都该变成“顶层主裁决”
- 有些体系更适合作为解释增强层、专题层、偏置层

这和 V17 现在的多专题并行架构是相容的。

### 4.2 需要纠偏的部分

#### 纠偏 1：`格局派 / 扶抑派 / 调候派` 不应拆成三个平行顶层门派

在当前系统里，更合理的表达是：

- `格局派`：归入 `ziping umbrella` 下的 `pattern_specializations`
- `扶抑派`：归入 `ziping umbrella` 下的 `balance / yongshen`
- `调候派`：已通过 `climate_field / climate_modifier_layer / classical.climate.*` 落地，并由 `classical.ziping.climate_bridge.v1` 归口到 `ziping umbrella`

原因：

- 这三者共享大量底层物理基础
- 它们并不是与盲派同层级的“完全独立世界观”
- 如果强行拆成多个平行顶层门派，会造成 authority 冲突、文档重复和 UI 混乱

#### 纠偏 2：`十神流 / 新派 / 象法` 更像方法层，而非立即独立成家族

当前系统里：

- `十神流` 已经部分存在于十神物理层、authority 分数、effect scores 中
- `新派` 过于宽泛，暂时不适合作为正式家族落地
- `象法` 已作为 `optional topic` 落地，当前保持 semantic-only，不进入 bias 或主 authority

也就是说，这三者更像：

- 一种解释语言
- 一种推理策略
- 一组额外专题

而不是当前阶段就要并列进主裁决树的顶层门派。

#### 纠偏 3：盲派不应覆盖子平主裁决

当前盲派专题的定位是对的，应该保持：

- `可选`
- `独立`
- `并行`
- `bias_only`

具体含义：

- 盲派输出 `blind_theme`
- 盲派输出 `blind_bias_protocol`
- authority 可吸收 blind 的 soft bias
- blind 不直接覆盖 `god_ring_authority`

这条边界已经落地，不建议倒退回“盲派单独主裁决”。

#### 纠偏 4：神煞、纳音不应进入核心 authority

建议维持当前原则：

- `神煞`：继续作为低权重辅助标签层
- `纳音`：暂不进入主线物理层与 authority

原因：

- 信息密度不足
- 容易污染主结构判断
- 解释意义大于物理意义

## 5. 当前架构下的门派/专题映射

### 5.1 子平 umbrella

建议继续视为当前系统的主裁决 umbrella，内部再分为三条子轴：

1. `balance axis`
- 对应：旺衰、扶抑、强弱平衡
- 当前已有：`month_command / balance / yongshen`

2. `pattern axis`
- 对应：古法格局、成格/破格、结构候选
- 当前已有：`pattern_specializations`

3. `climate axis`
- 对应：寒暖燥湿、调候优先
- 当前状态：缺失
- 建议未来新增：`climate_field` / `thermo_field`

### 5.2 盲派专题

当前已经完成正确落位：

- 独立可选专题
- 输出结构主通路、体态、家里家外、运行换挡
- 只并行进入 authority，不覆盖主裁决

这是一个“并行专题层”，不是新的底层宪法。

### 5.3 风险专题

`risk_matrix` 当前承担的是：

- 高风险结构
- 冲突逆转
- 风险偏置

这条线与门派无关，更接近系统级安全层，应继续独立存在。

### 5.4 神煞专题

神煞在 V17 更适合作为：

- 标签层
- 辅助叙事层
- 低权重提示层

而不进入主物理和主 authority。

## 6. 当前系统真正缺的是什么

### 6.1 最大缺口：调候轴

对齐分析师建议后，当前最明显的缺口不是“又一个门派”，而是：

- `寒 / 暖 / 燥 / 湿`
- `季节气候`
- `热力学调候`

当前系统已经有：

- 能量轴
- 稳定性轴
- authority 双轴
- relation dynamics
- runtime field

但没有真正的：

- `climate_field`
- `thermo_field`

所以如果下一步要从分析师建议里选一个真正值得新增的主轴，我认为应该优先做：

- `调候派的物理化建模`

### 6.2 第二缺口：象法轴

当前盲派里已经部分吸收了：

- 家里 / 家外
- 换挡
- 断口
- 做功链

但严格意义上的“象法系统”还没单独成专题。

如果未来要做，建议不要直接并入主裁决，而是新增：

- `xiangfa_theme`
- 仍然是 `optional topic`
- 输出 bias / evidence / narrative hint

这样能和 blind 保持对称，不污染主物理层。

## 7. 我们建议给分析师确认的几点

### 7.1 可以确认的共识

- `子平 umbrella` 作为当前主裁决体系保留
- `格局 / 扶抑 / 调候` 视为其内部三条子轴，其中格局和调候分别通过 bridge 插件归口到子平 umbrella
- `盲派` 继续作为独立并行专题
- `神煞` 保持辅助层
- `纳音` 暂不进入主线

### 7.2 需要分析师继续参与定义的点

1. `调候轴` 的正式变量设计  
建议分析师协助定义：
- 寒热
- 燥湿
- 得令/失令之外的气候修正
- 调候与十神结构的耦合方式

2. `象法专题` 的边界  
建议分析师先给出：
- 象法的最小可落地输出是什么
- 它应进入 bias/evidence 还是只进入 narrative

3. `多专题最终裁决权重`
- ziping 主裁决权重
- blind soft bias 权重
- future climate bias 权重
- future xiangfa bias 权重

## 8. 结论

这份分析师建议最值得采纳的，不是“把更多门派并列进系统”，而是：

- 把门派、专题、方法层、偏置层分清楚
- 从“多门派争主权”转向“共享物理 + 多专题并行 + authority 汇总”

对齐当前 V17，我的最终建议是：

1. 保持当前 `ziping / blind / pattern / risk / shensha` 五条线
2. 不新增多个平行顶层门派家族
3. 下一条真正值得新增的主轴是 `调候物理轴`
4. 未来若扩展 `象法`，也应采用和 blind 类似的 `optional topic` 方式并行接入

一句话总结：

**我们现在不缺“更多门派名称”，我们真正缺的是“调候这条底层场”和“象法这条并行专题轴”。**
