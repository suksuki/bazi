# V20 Five-Element Balance

V20 now compiles five-element distribution as a first-class feature.

## Contract

`feature.element.balance_distribution` is derived from visible stems and
hidden-stem weights. It can support foundation reading, health-boundary
projection, and useful-god review, but it cannot directly produce health
diagnosis, fixed fortune, or guaranteed events.

## Runtime Use

The element feature exposes:

- `q_element_balance`
- `q_element_support_pressure`
- reviewed knowledge refs for element distribution boundaries

This gives V20 a stronger Bazi measurement base without breaking the feature
spine guardrails.
