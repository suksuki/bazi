# V20 Useful-God Candidate Paths

V20 now compiles useful-god review as deterministic candidate paths.

## Contract

`feature.useful_god.candidate_paths` is derived from:

- day-master capacity from `CoreInference`
- five-element distribution from visible stems and hidden-stem weights
- support/pressure delta from the deterministic core

The feature can open support, release, channel, constraint, arbitration, or
evidence-gap paths. It cannot declare final favorable gods, unfavorable gods,
fixed fortune, or automatic remedies.

## Runtime Use

The useful-god candidate feature exposes:

- `q_useful_god_candidates`
- `q_useful_god_evidence_gaps`
- reviewed knowledge refs for candidate-path arbitration

This keeps V20 focused on Bazi measurement while preserving the P84 rule that
all conclusions must remain feature-backed and validation-bounded.
