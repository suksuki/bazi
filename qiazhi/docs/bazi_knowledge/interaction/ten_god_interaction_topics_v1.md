# 十神组合类知识 v1

状态：命理师审阅目录

范围：记录十神之间的经典组合、作用关系、结构碰撞和化解路径。这里不是单个十神定义，也不是完整格局判定，而是一个独立的八字知识类别。

## 类别定义

“伤官见官”“枭神夺食”这一类，正式归入：

```text
十神组合类知识
```

它的定位是：

```text
单个十神知识 < 十神组合类知识 < 格局 / 领域机制 / 盲派做功
```

这类知识不适合只放在单个十神下面：

- 它至少涉及两个十神。
- 它需要看来源层：透干、藏干、月令、地支、时间背景。
- 它需要看强弱、位置、清浊、是否有救应。
- 它容易被传统断语污染，不能直接作为预测结论。

所以本目录不是临时专题列表，而是知识库里的正式类别。

## 审阅规则

- 第一层只确认“组合是否出现”，不下结论。
- 第二层再看来源层、宫位、强弱、月令、是否混杂。
- 第三层才讨论机制：制、化、生、泄、夺、合、冲、救应。
- 没有合成测试前，不输出吉凶、职业、婚姻、财富、健康断语。

## 与其他目录的关系

- 与 `ten_god/`：十神目录定义单个十神，本目录处理多个十神之间的作用。
- 与 `strength/`：强弱决定作用是否有力，但不直接等同结果。
- 与 `pattern/`：部分组合可成为格局成败条件，但必须另入格局专题。
- 与 `wealth/`：比劫夺财、食伤生财、财生官等可成为财富机制候选。
- 与 `blind/`：做功、宾主、体用可解释这些组合如何发生作用。
