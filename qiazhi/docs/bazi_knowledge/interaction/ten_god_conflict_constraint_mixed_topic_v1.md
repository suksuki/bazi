# 十神冲突 / 牵制 / 混杂专题 v1

状态：P28F 专题审阅目录

范围：把“伤官见官”这一类容易被传统断语污染的十神组合集中处理。这里处理的不是单个十神，也不是完整格局，而是多个十神之间的冲突、牵制、夺破、混杂、去留与救应边界。

## 为什么单独成专题

这类知识有共同特征：

- 名称本身带有强烈断语倾向，如见官、夺食、破印、攻身、混杂。
- 最低层其实只是结构事实：哪些十神同时出现，来自透干还是藏干，发生在本命还是时间层。
- 机制层必须补上下文：强弱、来源层、宫位、月令、是否有救应、是否被合化去留。
- 领域结论必须后置：事业、财富、婚姻、健康、官非、破财等都不能由名称直接推出。

所以这一类统一归入：

```text
interaction/ten_god_conflict_constraint_mixed
```

## 规则化顺序

统一按四层处理：

| 层级 | 目标 | 可规则化程度 |
|---|---|---|
| 组合存在 | 只确认涉及十神同时出现 | R1，可入 Rule DB 候选 |
| 机制边界 | 说明牵制、夺破、混杂、去留、救应路径 | R2，可入 Rule DB 候选 |
| 条件模型 | 来源层、强弱、月令、宫位、时间层组合 | R2/R3，需合成盘测试 |
| 传统断语 | 官非、破财、疾病、婚姻、贵贱、应期 | R3/R4，归档，不直接输出 |
