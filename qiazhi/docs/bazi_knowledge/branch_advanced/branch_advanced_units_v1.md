# 地支高级关系知识单元 v1

状态：第一轮目录补齐

范围：记录穿、绝、暗合等地支高级关系。当前只作为结构关系候选，不直接进入吉凶、事件、六亲或应期判断。

## 治理边界

- 先确认关系是否出现，再看来源层、宫位、强弱、是否与三合六合刑冲害破冲突。
- 高级地支关系必须低于基础关系优先级，不能覆盖六合、六冲、三合、三会、墓库等基础结构。
- 没有专题合成样本前，只能输出“关系候选”和“需要复核的结构点”。

## 审阅点

- 穿：只作为互相损伤或牵制的关系名候选，不能直接断灾。
- 绝：只作为关系断裂或气势不续的候选标签，不能直接断结果。
- 暗合：只作为隐性牵连候选，必须区分本命、藏干、时间层。
