# 命理知识专题审阅队列 v1

状态：专题式 review 计划

## 主线顺序

当前阶段的主线不是先做自我学习，而是：

```text
先按知识类别审阅
再按类别转规则
最后做自我学习和合成验证扩展
```

每完成一类知识，才进入对应的规则转化。这样可以避免规则库建立在缺失或混乱的知识目录上。

## 为什么要专题审阅

让分析师或命理师一次审完整个知识库会很难。更适合按专题拆小：

```text
一个专题
一组典型合成盘
一批知识单元
一组规则候选
一次回归
```

这样 ChatGPT 这类分析师也更容易给出有效意见，不会在庞大目录里泛泛而谈。

## 每个专题的固定审阅模板

```text
1. 专题名称
2. 传统名称别名
3. 涉及十神 / 五行 / 宫位 / 地支关系
4. 最低结构事实
5. 必须补充的上下文
6. 可以输出的结构解释
7. 禁止输出的断语
8. 合成盘测试场景
9. 可进入 Rule DB 的低风险规则
10. 必须保留为归档的高风险内容
```
