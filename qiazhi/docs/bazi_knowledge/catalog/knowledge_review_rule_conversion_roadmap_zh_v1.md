# 八字知识审阅与规则转化主线 v1

状态：主线策略

日期：2026-04-30

## 核心判断

当前阶段不要先做“自我学习”“自动进化”“大规模调参”。这些能力必须建立在相对完整的知识目录和规则目录上。

正确顺序是：

```text
一类八字知识
一轮命理审阅
一批结构化知识单元
一批规则候选
一轮规则转化
一轮小回归
进入下一类
```

等主要知识类别和规则候选完成后，再进入：

```text
自我学习框架
合成数据矩阵扩展
参数调优
智能门禁扩大
长期回归
```

## 阶段划分

### 阶段 A：知识类别补全

目标：先把命理知识目录补完整，不追求立即全部启用。

优先级：

1. 十神组合类知识
2. 盲派理法
3. 宫位象法
4. 格局正格
5. 大运流年引动
6. 地理信息与排盘边界
7. 格局成败
8. 特殊格局
9. 神煞象意
10. 纳音、胎元、命宫、身宫

### 阶段 B：规则转化

目标：每完成一类知识，就转化一批规则候选。

规则分层：

| 层级 | 内容 | 处理方式 |
|---|---|---|
| R1 | 结构事实、组合存在、来源层、边界 | 可进 Rule DB 候选，可通过小回归启用 |
| R2 | 作用机制、制化路径、救应条件 | 进 Rule DB 候选，默认不急于启用 |
| R3 | 传统断语、特殊格局、盲派技法 | 归档 + 合成测试，不直接启用 |
| R4 | 高风险断事、应期、疾病、灾祸 | 归档，不进规则 |

### 阶段 C：专题式 review

每类知识都用固定模板审阅：

```text
1. 类别名称
2. 子类目录
3. 传统术语
4. 最低结构事实
5. 必须补充上下文
6. 可转规则的低风险内容
7. 只能归档的高风险内容
8. 需要构造的合成盘
9. 回答表达边界
10. 是否允许进入 Rule DB
```

### 阶段 D：自我学习与合成验证

只有在阶段 A-C 有足够覆盖后再做。

后置原因：

- 没有完整知识目录，系统无法知道缺口在哪里。
- 没有规则候选，合成数据只能测 UI 和问答表层。
- 没有分类风险，智能审批容易把断语当规则。
- 命理知识本身歧义大，必须先类别化、结构化。
