## 目录原则

V20 知识库不再按工程模块平铺，也不再把“财富、事业、关系”等应用主题当作源头。源头目录必须先覆盖八字测算本体，再由本体推到应用。

目录分四层：

1. 宏观层：命局总势、月令气候、格局、体用、岁运层级。
2. 微观层：天干地支、十神、藏干、刑冲合害破墓、做功、制化。
3. 应用层：财富、事业、婚恋、家庭、学业、健康、迁移等主题投影。
4. 归档层：神煞、纳音、胎元命宫身宫、口诀技法等高风险或辅助体系。

每个目录后续补内容时，必须包含：

- 传统名称与别名
- 所属层级：宏观 / 微观 / 应用 / 归档
- 最低结构事实
- 必须补充的上下文
- 可输出的结构解释
- 禁止输出的断语
- 可转规则的低风险条件
- 必须归档的高风险内容
