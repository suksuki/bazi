# 八字知识库缺口审阅报告 v1

状态：Codex 外部目录对照审阅

日期：2026-04-30

## 结论

当前知识库已经具备核心结构、十神、强弱、财富、时间层和回答表达的骨架，但还不是完整命理知识库。

最大缺口有三个：

1. 盲派目前只有零散的高风险占位，没有形成“理法 / 象法 / 技法”的目录。
2. 格局目前只有 5 条候选边界，没有覆盖正格、变格、成败、相神、清浊、混杂等体系。
3. 十神组合类知识没有独立体系，例如“伤官见官”“枭神夺食”“食神制杀”“杀印相生”这一类还没有系统归类。

## 外部目录对照

### 格局体系缺口

外部资料和传统目录通常至少会拆成：

- 十神正格：正官格、七杀格、正财格、偏财格、食神格、伤官格、正印格、偏印格。
- 禄刃格：建禄格、羊刃格。
- 变格 / 特殊格：从财、从杀、从儿、从旺 / 从强、专旺、化气。
- 专旺五格：曲直、炎上、稼穑、从革、润下。
- 化气五格：甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火。
- 格局成败：成格、破格、救应、相神、忌神、清浊、混杂。
- 月令取格边界：以月令为入口，但不能把月令直接当结果。

当前我们只有：

- 官格候选
- 财格候选
- 食伤格候选
- 印格候选
- 从格 / 化格高风险边界

所以格局完成度很低，约 15%。

### 盲派体系缺口

外部资料通常把盲派拆成三层：

- 理法：阴阳五行、干支作用、刑冲合害破墓、宾主、体用、做功、效率、干支配置。
- 象法：干支象、宫位象、十神象、神煞象、换象、带象、类象。
- 技法：口诀、案例经验、断事模板、盲师经验规则。

当前我们只有一条 `blind_symbolic` 占位，不能支撑盲派 review。

盲派不适合直接全量启用规则，因为技法和断语风险极高；但它适合先建三层目录：

- `blind/lifa/`：理法，可优先转成结构规则候选。
- `blind/xiangfa/`：象法，先做解释标签和归因，不输出事件断语。
- `blind/jifa/`：技法口诀，先归档和合成测试，不直接进入 engine。

### 十神组合类知识缺口

“伤官见官”“枭神夺食”这一批，是一个独立的八字知识类别，不应只放在单个十神目录里，也不应直接归入格局。它们更准确的目录是：

```text
interaction/ 十神组合类知识
```

建议先拆四类：

- 冲突类：伤官见官、枭神夺食、比劫夺财、财破印、官杀混杂。
- 制化类：食神制杀、伤官制杀、杀印相生、印化杀、伤官配印。
- 生助路径类：食伤生财、财生官、官印相生、财官相生。
- 夺泄牵制类：印制食伤、食伤泄身、财滋杀、比劫分财。

这些专题第一阶段只记录结构关系和作用机制，不输出传统断语。

## 优先级判断

第一优先级不是继续补财富，而是：

```text
盲派理法 + 宫位象法 + 十神组合类知识 + 格局正格
```

原因：

- 盲派“做功 / 宾主 / 体用”可以反过来改善收入、事业、关系的结构解释。
- 宫位是盲派和传统子平都会用到的基础层，现在完全缺失。
- 十神组合类知识是连接十神、强弱、格局、财富机制的中间层，现在缺失会导致很多专业术语无法归类。
- 格局正格是专业命理师 review 绕不开的目录，现在覆盖太浅。

## 主线顺序修正

当前不要先扩大自我学习和自动进化。主线应调整为：

```text
一类一类补八字知识
一类一类做命理 review
一类一类转规则候选
小回归确认不污染回答
再进入下一类
```

等十神组合类、盲派理法、宫位象法、格局正格等主干知识完成后，再进入自我学习、合成数据扩展和参数优化。

## 风险边界

- 盲派技法口诀：R3-R4，先归档，不自动启用。
- 特殊格局：R3，先合成测试，不自动启用。
- 神煞、纳音：R3-R4，先做象意归档，不进入结论。
- 宫位和理法：R1-R2，可优先结构化。
