# 八字知识总目录 v1

状态：总目录先行版

日期：2026-04-30

## 目标

先建立一个相对全面的八字知识地图，再一类一类补内容、转规则、做回归。

原则：

- 目录先行，内容后填。
- 每个知识点先归类，再决定是否规则化。
- 低风险结构知识优先，高风险断语先归档。
- 真实命盘不作为当前训练基础，先用合成盘验证。

## 状态标记

| 标记 | 含义 |
|---|---|
| 已有 | 已有知识文档和结构化草案 |
| 部分 | 有一些 seed 或文档，但不完整 |
| 缺失 | 目录还没建或没有结构化知识 |
| 归档 | 可记录，但暂不进入规则 |
