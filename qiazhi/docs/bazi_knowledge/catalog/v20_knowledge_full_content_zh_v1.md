## 总原则

V20 八字知识库以“测算主线”为核心，不以应用话术、画像标签或问题推荐为源头。所有内容必须服务于：

```text
八字事实
-> 命理机制链
-> 反证裁决
-> 主题投射
-> 用户问题
-> 证据化回答
```

每个知识点都必须能回答：

- 它依赖哪些八字事实。
- 它发现什么特征。
- 它进入哪条机制链。
- 它有哪些反证。
- 它能投射到什么主题。
- 它禁止输出什么断语。

## L0 排盘与基础符号

### L0.1 天干

十天干为甲、乙、丙、丁、戊、己、庚、辛、壬、癸。天干是外显之气，优先用于判断透出、作用方向、天干合克、日主定位和十神显性材料。

测算作用：

- 确定日主。
- 确定天干五行阴阳。
- 确定明透十神。
- 判断天干生克、合化、合绊、合动。
- 作为外显事件、表达方式、可见资源的结构材料。

证据要求：

- 天干所在柱位。
- 与日主的十神关系。
- 是否受合、克、冲、制化。
- 是否有地支根气承接。
- 是否有月令季节支持。

边界：

- 不可只凭一个天干定格局高低。
- 不可只凭天干透财、透官、透印直接断财富、事业、学历或贵人。

### L0.2 地支

十二地支为子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥。地支为内藏之气，承载藏干、根气、宫位、关系、库墓、季节和时间触发。

测算作用：

- 判断藏干与主气、中气、余气。
- 判断日主是否有根。
- 判断地支合冲刑害破穿。
- 判断宫位落点。
- 判断墓库开闭。
- 判断岁运引动。

证据要求：

- 地支所在柱位。
- 藏干组成。
- 与其他地支关系。
- 是否被岁运冲合引动。
- 所藏十神是否能透出或做功。

边界：

- 不可见冲即断凶。
- 不可见合即断好。
- 不可见墓库即断财库、婚库、官库成立。

### L0.3 四柱

四柱为年柱、月柱、日柱、时柱。四柱不是同权结构，月令为气候和格局核心，日柱为主体和夫妻宫，年柱偏外部、祖上、早年背景，时柱偏后续、子女、晚景、输出端。

测算作用：

- 分远近、内外、早晚、主客。
- 确定日主与日支。
- 确定月令和季节核心。
- 确定宫位投射。
- 确定十神来源层。

证据要求：

- 每柱天干地支。
- 柱位权重。
- 月令状态。
- 日主与日支关系。
- 时柱是否准确。

边界：

- 不可把年柱、月柱、日柱、时柱混作同一层证据。
- 时辰不确定时，时柱相关判断必须降级为候选。

### L0.4 历法与排盘元数据

排盘元数据包括节气、立春换年、真太阳时、出生地、时区、夏令时、历史时区和经度校正。排盘准确性是知识库最底层事实。

测算作用：

- 决定年柱、月柱和时柱是否可靠。
- 决定月令。
- 决定时间层不确定性。
- 决定后续所有特征是否可用。

边界：

- 出生地或时辰不确定时，必须标记不确定性。
- 不可用 LLM 或用户模糊描述生成 ChartFacts。

## L1 五行与气候

### L1.1 五行基础

五行为木、火、土、金、水。五行关系包括生、克、泄、耗、助、制、化、通关。五行不是简单数量统计，而是气的流动、制约与承接。

测算作用：

- 判断结构偏性。
- 判断日主扶抑。
- 判断用神候选。
- 判断通关和制化。
- 判断气候调候。

证据要求：

- 天干五行。
- 地支藏干五行。
- 月令季节。
- 透藏层级。
- 生克路径是否连续。

边界：

- 不可只凭五行个数断喜忌。
- 不可把五行偏枯直接转成疾病判断。

### L1.2 五行分布

五行分布包括数量、透出、藏干、集中、偏枯、流通、阻滞。分布是原局结构的材料，不是最终结论。

判断重点：

- 哪一行明显偏显。
- 哪一行明显偏弱或缺位。
- 偏显是否有制化。
- 偏弱是否为用、为忌、为病。
- 五行是否形成流通链。

反证：

- 偏显但被制化。
- 偏弱但不需要。
- 缺位但由组合或岁运补出。
- 数量多但无根无力。

### L1.3 寒暖燥湿与调候

寒暖燥湿由月令、季节、火水状态、燥湿土、地域气候背景共同决定。调候与强弱不同，不能混为一谈。

测算作用：

- 判断结构舒展程度。
- 判断调候路径。
- 判断用神候选优先级。
- 判断健康主题只能作为节律与平衡边界。

边界：

- 寒暖燥湿不可直接断疾病。
- 调候不可直接等于最终用神。

## L2 强弱与承载

### L2.1 日主承载

日主强弱不是单点判断，必须合看得令、得地、得势、得助、失令、失地、失势，以及泄耗克压力。承载力决定财富、事业、关系、健康等主题能否被接住。

测算作用：

- 判断是否能承财。
- 判断是否能任官杀。
- 判断食伤泄秀是否过度。
- 判断印比是否必要。
- 判断用神路径。

状态：

- confirmed：多层证据一致。
- candidate：证据成立但仍需补充。
- weak_candidate：单层证据或边界状态。
- mixed：扶助与压力并见。
- requires_review：强弱接近分界。

边界：

- 不可只凭月令定强弱。
- 不可只凭比劫或印星数量定强弱。

### L2.2 根气

根气包括通根、本气根、中气根、余气根、禄、刃、墓库根、虚根。根气决定天干是否有承接和持续性。

判断重点：

- 日主是否通根。
- 根在何柱。
- 根是否被冲、合、刑、害。
- 根是本气、中气还是余气。
- 根是否被岁运引动。

反证：

- 有根但被冲动。
- 有根但远隔。
- 有墓库根但未开。
- 透干强但无根。

### L2.3 扶抑压力

印星扶身、比劫帮身、食伤泄身、财星耗身、官杀克身，共同构成扶抑压力。强弱判断必须把扶助和压力放在同一张证据表里。

路径：

- 扶身路径。
- 泄秀路径。
- 制杀路径。
- 通关路径。
- 病药路径。

边界：

- 扶身不等于好。
- 泄秀不等于坏。
- 克身不等于灾。

## L3 十神系统

### L3.1 十神本体

十神为比肩、劫财、食神、伤官、偏财、正财、七杀、正官、偏印、正印。十神是日主与其他干支五行阴阳关系的结构语言。

基础含义：

- 比肩：同类、自主、并行、同辈。
- 劫财：竞争、分夺、行动、外放。
- 食神：输出、稳定表达、产出。
- 伤官：突破、表达、反规则、技术。
- 偏财：流动资源、机会、外部财。
- 正财：稳定资源、管理、现实承接。
- 七杀：压力、竞争、风险、规则强压。
- 正官：规则、秩序、身份、约束。
- 偏印：非常规吸收、偏门、保护、阻食。
- 正印：学习、资源、承接、保护。

边界：

- 十神是结构关系，不是人格标签。
- 不可把某一十神直接转成职业、财富、婚姻结论。

### L3.2 十神来源层

十神要区分明透、藏干、重复、月令、柱位、远近、内外。

判断重点：

- 明透十神：外显、可见、易被触发。
- 藏干十神：内藏、条件触发、需要引动。
- 月令十神：气候与格局核心。
- 日支十神：贴近日主与关系宫。
- 时柱十神：输出、后续、子女、晚景。

反证：

- 明透但无根。
- 藏干但未引动。
- 重复但被制化。
- 月令强但被破。

### L3.3 十神组合与机制

核心组合：

- 伤官见官：表达与规则冲突，需看印星缓冲、强弱承载、位置。
- 枭神夺食：偏印压制输出，需看财星制枭、食神来源。
- 食神制杀：输出制压力，需看食神有力、杀有制。
- 杀印相生：压力转资源，需看印是否承杀。
- 官印相生：规则与资源相生，需看清浊。
- 伤官配印：表达受印化，需看印是否有力。
- 食伤生财：输出转财，需看日主承载。
- 财生官：财推动规则身份，需看官是否清。
- 比劫夺财：同类分财，需看财星来源与承载。
- 财破印：现实资源冲击印星，需看印是否为核心。
- 官杀混杂：规则与压力混杂，需看去留清浊。
- 印枭混杂：资源来源混杂，需看是否阻食。

边界：

- 组合成立必须看位置、强弱、透藏、反证。
- 不可见组合名就输出吉凶。

## L4 干支关系

### L4.1 天干关系

天干关系包括五合、合化、合绊、合动、合而不化、天干冲、天干克、制化、通关。

判断重点：

- 合的双方是谁。
- 是否有月令支持化气。
- 是否有化神。
- 是合化、合绊还是合动。
- 合后影响哪个十神和主题。

边界：

- 见合不等于化。
- 见克不等于凶。

### L4.2 地支关系

地支关系包括六合、六冲、三合、半合、三会、刑、害、破、穿、墓库、伏吟、反吟、拱夹、暗合、遥合。

判断重点：

- 关系类型。
- 关系方向。
- 涉及宫位。
- 涉及藏干。
- 是否引动墓库。
- 是否有岁运参与。

反证：

- 有冲但被合。
- 有合但不化。
- 有刑害但无落点。
- 有墓库但不开。

边界：

- 不可把冲合刑害破统一当作吉凶符号。

## L5 格局系统

### L5.1 格局入口

格局先从月令、透干、藏干、十神主气和全局清浊入手。格局是结构组织方式，不是命运等级标签。

正格：

- 财格。
- 官格。
- 杀格。
- 印格。
- 食神格。
- 伤官格。
- 建禄。
- 月劫。

特殊格：

- 从格。
- 专旺。
- 化气。
- 其他门派特殊格归档。

判断重点：

- 月令取格是否成立。
- 透干是否清。
- 格局是否被破。
- 是否需要用神配合。
- 是否与做功形成一致主线。

边界：

- 不可提前定格局等级。
- 不可用格局名直接断富贵贫贱。

## L6 用神与取用路径

用神判断必须先列候选路径，不可直接定喜忌。路径包括扶抑、调候、通关、病药、泄秀、制杀。

测算流程：

```text
强弱承载
-> 五行气候
-> 生克流通
-> 十神机制
-> 反证
-> 候选路径
-> 裁决状态
```

候选路径：

- 扶抑：处理强弱失衡。
- 调候：处理寒暖燥湿。
- 通关：处理两气交战。
- 病药：找结构病点与药点。
- 泄秀：强旺有输出。
- 制杀：压力需要制化。

边界：

- 用神候选不等于最终喜忌。
- 岁运可改变路径权重，但不改原局事实。

## L7 宫位与象法

宫位用于定位结构落点。年、月、日、时有不同远近内外和主题侧重。

宫位：

- 年柱：外部、祖上、早年、远端背景。
- 月柱：父母、环境、事业平台、月令核心。
- 日柱：主体、夫妻宫、贴身关系。
- 时柱：输出、子女、后续、晚景。

判断重点：

- 关系落在哪个宫位。
- 宫位是否被冲合刑害。
- 宫位藏干是什么。
- 宫位与十神是否一致。
- 岁运是否引动宫位。

边界：

- 宫位象不能直接推断隐私事实。
- 夫妻宫受冲不等于必离婚。

## L8 盲派系统

盲派内容在 V20 中作为机制与象法层，不绕过证据链。重点包括宾主、体用、做功、宫位象、干支象、十神象、位置象、应期象。

### L8.1 宾主体用

判断谁为主、谁为宾，谁为体、谁为用。主客体用决定作用方向和是否入主。

证据要求：

- 日主与日支。
- 宫位落点。
- 十神来源。
- 做功方向。
- 是否入主。

### L8.2 做功

做功关注谁对谁作用，通过什么媒介，路径是否连续，是否被阻断，结果是否被日主或主题承接。

做功链：

```text
主体
-> 作用对象
-> 媒介
-> 路径连续性
-> 阻断/反证
-> 承接/不承接
```

应用：

- 财的做功：财来就我、我去取财、财被分夺、财入库。
- 官杀做功：规则压力、职位平台、杀印转化、食伤冲官。
- 印星做功：资源承接、学习吸收、化杀、阻食。
- 食伤做功：输出、技术、表达、生财、制杀。

边界：

- 象法只作入口线索，必须回到结构证据。
- 不可用盲派象法输出隐私断语。

## L9 岁运时间系统

时间层分原局、大运、流年、流月。原局定结构，大运定阶段背景，流年流月作触发窗口。

判断重点：

- 大运是否改变五行背景。
- 大运十神是否补出或压制原局机制。
- 流年是否冲合刑害原局。
- 岁运是否打开墓库。
- 时间层是否使候选变为 volatile。

边界：

- 不可断精确日期。
- 不可把流年触发等同于必然事件。
- 没有提供大运流年时，不输出时间判断。

## L10 领域应用

应用层不是知识源头，而是 TopicProjection。财富、事业、关系、感情、健康都必须从 BaziFeature 和 DecisionState 投射。

### L10.1 财富

目录关键词：财富财星材料、财富食伤生财、财富财库开闭、财富比劫分夺、财富承载与现金流。

证据链：

```text
财星材料
-> 财星来源层
-> 食伤生财通道
-> 日主承载
-> 比劫分夺
-> 财库开闭
-> 官杀印星改写
-> 岁运引动
```

输出焦点：

- 材料。
- 机会。
- 通道。
- 承接。
- 波动。
- 风险。

禁止：

- 不断发财破财。
- 不断金额、投资结果、债务结果。

### L10.2 事业

证据链：

```text
官杀规则
-> 食伤表达
-> 印星缓冲
-> 格局承接
-> 日主承载
-> 地支互动
-> 岁运触发
```

输出焦点：

- 规则压力。
- 平台资源。
- 表达冲突。
- 学习转化。
- 承接边界。

禁止：

- 不断升职、降职、失业、官非结果。

### L10.3 关系

证据链：

```text
比劫互动
-> 十神关系
-> 地支互动
-> 宫位落点
-> 资源分配
-> 承接边界
```

禁止：

- 不推断第三方隐私。
- 不断合作成败、背叛、纠纷结果。

### L10.4 感情

证据链：

```text
配偶星
-> 夫妻宫
-> 合冲刑害
-> 十神互动
-> 原局承接
-> 岁运引动
```

禁止：

- 不断结婚离婚时间。
- 不断伴侣身份、外遇、私密事实。

### L10.5 健康

证据链：

```text
五行偏枯
-> 寒暖燥湿
-> 承载压力
-> 时间节律
-> 恢复边界
```

禁止：

- 不诊断疾病。
- 不预测发病。
- 不替代医疗建议。

## L11 辅助体系与归档

辅助体系包括神煞、纳音、胎元、命宫、身宫、空亡、十二长生、口诀技法、门派异文。这些内容进入归档层，不作为主裁决依据。

晋升条件：

- 有清晰来源。
- 有结构证据。
- 有反证规则。
- 有安全边界。
- 通过命理师审核。
- 通过 synthetic case。

边界：

- 神煞不可单独断事。
- 纳音不可覆盖五行十神主线。
- 口诀不可绕过 EvidencePack。

## L12 回答表达与治理

回答必须证据化、边界化、候选化，不输出命运断语。

表达状态：

- confirmed：明确成立，但只说结构成立。
- candidate：候选成立，提示需补证据。
- weak_candidate：弱候选，优先追问。
- blocked：被阻断，不投射。
- countered：有反证，降级表达。
- mixed：成而不纯，支持与杂质同说。
- volatile：岁运引动后波动，绑定时间层。
- requires_review：需要命理师复核。
- out_of_scope：证据不足，不输出。

LLM 边界：

- LLM 可做表达、追问、摘要。
- LLM 不生成 ChartFacts。
- LLM 不裁决用神格局。
- LLM 不绕过 EvidencePack。
- LLM 输出必须经过 Verifier。

禁止表达：

- 必然。
- 注定。
- 保证。
- 一定发财。
- 一定离婚。
- 必有疾病。
- 准确日期。
- 医疗、法律、金融结论。
