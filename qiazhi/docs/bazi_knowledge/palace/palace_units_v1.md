# 宫位象法知识单元 v1

状态：P31A 基础目录补齐。

## 治理边界

宫位只作为结构来源和位置标签。年、月、日、时可以帮助说明结构离日主远近、内外、早晚和承载位置，但不能直接判断祖上、父母、婚姻、子女、事业或晚年结果。

## 第一批主题

| 主题 | 当前定位 | 风险 |
|---|---|---|
| 年柱 | 远、外、早期背景 | R1 |
| 月柱 | 月令入口、结构环境 | R1 |
| 日支 | 贴身、内在承载 | R2 |
| 时柱 | 后段、结果端位置 | R2 |
| 天干外显 / 地支内在 | 显隐来源层 | R1 |
| 远近 / 内外 | 距离与位置标签 | R2 |
| 宫位与十神组合 | 双重来源层 | R2 |

## 规则化边界

- 必须标明柱位和来源层。
- 宫位只能调整回答焦点，不生成领域结果。
- 宫位与十神同见时，需要同时保留十神标签和宫位标签。
