# 正格知识单元 v1

状态：P31A 基础目录补齐。

## 治理边界

正格当前只作为候选结构，不确认成格。任何格局候选都必须经过月令、透干、根气、清浊、制化、救应和日主承载审核。

| 格局 | 当前定位 | 风险 |

| 正官格 | 候选，不断职业权力 | R2 |
| 七杀格 | 候选，不断风险权力 | R2 |
| 财格 | 候选，不断财富结果 | R2 |

## 规则化边界

- 不输出成格、破格、贵贱、高低。
- 必须进入条件模型与正反样本验证。
- 与十神机制同见时，先由 P30 仲裁层决定回答焦点。
