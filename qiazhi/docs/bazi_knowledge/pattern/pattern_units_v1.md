# 格局知识单元 v1

状态：命理师审阅版目录

范围：格局候选与格局阅读边界。当前只标记可能需要检查的格局证据，不启用格局断语。

## 治理边界

- 在格局模型独立审核前，格局单元只作为候选标签。
- 格局候选必须保留来源证据：月令、透干、藏干、根气和关系语境。
- 从格、化格、特殊格局属于高风险，未单独审核前不启用。
- 格局候选可用于合成盘测试、规则草案审阅和回答边界控制。

## 审阅边界

格局证据可以回答：

- 哪些结构事实让某个格局值得检查。
- 哪些证据是透出的，哪些是藏的。
- 还缺哪些关系证据或强弱证据。

格局证据不能回答：

- 未经模型审核就确认格局。
- 用格局决定用户命运。
- 让特殊格局绕过正常证据检查。
