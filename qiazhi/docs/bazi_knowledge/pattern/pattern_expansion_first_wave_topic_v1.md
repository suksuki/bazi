# 格局细化第一批专题 v1

状态：P33 新知识审阅目录

## 定位

P33 补的是格局知识本体，不是规则审批链路。此前知识库已有“正格/特殊格局只作候选”的安全边界，但对命理师审阅来说太粗。本专题把取格来源、正格细目和特殊格局的真伪边界拆成可检查对象。

## 通用条件轴

所有格局对象先看这些轴：

- `source_layer`：格局来源在月令、本气、透干、藏干、会合成势还是时间层。
- `month_command_role`：月令是否为取格核心，还是只提供季节背景。
- `stem_visibility`：格局之神是否透干，透出位置是否清楚。
- `root_and_capacity`：格局之神是否有根，日主是否能承载。
- `clarity_mixture`：是否混杂、重叠、同类互扰。
- `rescue_or_damage_path`：是否有制化、救应、破格、伤格路径。
- `time_layer_boundary`：大运流年只能引动或加重，不直接改写本命格局。

## 第一批格局对象

| 对象 | 结构含义 | 安全边界 |
|---|---|---|
| 月令取格 | 以月令主气或可用藏干作为格局入口 | 只确认来源，不确认成格 |
| 透干成格 | 格局之神透出，使结构更可见 | 不等于格局成立 |
| 杂气取格 | 辰戌丑未等杂气支中取可用藏干 | 必须区分主气、中气、余气 |
| 正官格 | 月令或透干见正官的候选结构 | 不断职业、权力、贵气 |
| 七杀格 | 七杀成势或当令的候选结构 | 必须看制化，不断风险结论 |
| 财格 | 财星当令、透出或成势的候选结构 | 必须看日主承载和比劫牵制 |
| 食神格 | 食神当令或透出的输出候选结构 | 必须看印枭牵制与财星承接 |
| 伤官格 | 伤官当令或透出的输出候选结构 | 必须看见官、配印、生财 |
| 印格 | 印星当令或透出的支持候选结构 | 必须看财星破印与日主需求 |
| 建禄格 | 日主临禄、同类根气明显的候选结构 | 不等于身旺富贵 |
| 羊刃格 | 刃气显著的高压同类结构 | 必须看官杀制化和泄秀 |
| 从财格 | 日主极弱而财势主导的从格候选 | 假从反例优先 |
| 从杀格 | 日主极弱而官杀主导的从格候选 | 必须看印比破从 |
| 从儿格 | 日主顺食伤输出之势的从格候选 | 必须看印星回克 |
| 专旺格 | 同一五行成势、顺其旺气的特殊候选 | 必须排除杂气破局 |
| 化气格 | 天干五合有化气条件的特殊候选 | 合而不化是关键反例 |

## 规则化边界

- 本专题只补知识，不直接启用格局规则。
- 正格知识可以进入后续条件模型；特殊格局先归档和反例优先。
- 回答时只能说“格局候选、来源、边界、需补充的条件”，不能直接说成格、破格、富贵贫贱、职业层级。
- 时间层触发只能作为背景或引动，不能改写本命取格。
