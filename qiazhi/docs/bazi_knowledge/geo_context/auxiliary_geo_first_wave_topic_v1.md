# 地理与辅助体系第一批专题 v1

状态：P37 新知识审阅目录

## 定位

P37 补地理信息、历法校验、十二长生、神煞、纳音、辅助柱、空亡、用神忌神等辅助体系。它们多数不是主推理链，只能作为排盘元数据、结构背景或归档标签。

## 处理原则

- 地理和历法优先作为排盘校验元数据，不直接进入命理解读结论。
- 地域气候可以作为调候背景候选，但不能覆盖月令、强弱、格局。
- 神煞、纳音、空亡、辅助柱默认 archive-first。
- 用神忌神默认不启用，不输出喜用、忌神、补五行建议。
