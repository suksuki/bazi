# 地理信息与环境背景知识单元 v1

状态：总目录占位 + 命理师审阅目录

范围：记录出生地、时区、经纬度、真太阳时、地域气候等与八字排盘和结构解释有关的时空背景。当前不把地理信息直接转成命运结论。

## 为什么需要单独目录

地理信息不是传统四柱中的第五柱，但它会影响两个层面：

- 排盘层：出生地、时区、经度可能影响时间校正和时柱边界。
- 解释层：地域气候、南北寒暖燥湿可作为调候或环境背景参考。

它不能直接输出：

- 地域决定命运。
- 出生地决定贫富贵贱。
- 搬家、迁移、城市选择等预测。

## 规则化边界

| 子类 | 风险 | 规则化策略 |
|---|---|---|
| 出生地时区 | R1 | 可作为排盘校验元数据 |
| 经度 / 真太阳时边界 | R2 | 只提示边界，不自动改盘 |
| 夏令时 | R2 | 只做校验提示 |
| 地域气候 | R2 | 只作为调候背景候选 |
| 南北寒暖 | R2 | 只作为环境语境 |
| 出生地与居住地差异 | R3 | 先归档 |
| 迁移地域影响 | R4 | 暂不规则化 |
