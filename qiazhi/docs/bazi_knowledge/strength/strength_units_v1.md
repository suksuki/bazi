# 强弱知识单元 v1

状态：命理师审阅版目录

范围：日主承载力与结构强弱的证据模型。这里不判喜忌，不输出吉凶或运势结论。

## 治理边界

- 强弱是一组证据，不是单一断语。
- 月令、根气、透出支持、藏干支持、泄耗、克制压力必须拆开记录。
- 用神、喜忌、旺衰裁决在独立模型审核前不进入自动判断。
- 强弱信号可以辅助推荐问题和回答解释，但不能单独改写结果。

## 规范特征类型

## 审阅边界

强弱证据可以回答：

- 月支是什么，与日主五行如何形成环境关系。
- 日主是否有透出或藏干层面的同类根气。
- 支持、泄耗、克制压力是否作为独立事实出现。
- 证据是清楚、混合，还是仍应保持中性。

强弱证据不能回答：

- 哪个五行是喜用。
- 命盘是否好运。
- 财富或事业结果好坏。
