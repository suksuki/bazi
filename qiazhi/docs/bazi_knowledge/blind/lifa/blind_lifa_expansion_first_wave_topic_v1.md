# 盲派理法细化第一批专题 v1

状态：P34 新知识审阅目录

## 定位

P34 补盲派理法的结构化知识本体。当前不引入口诀式断语，也不把盲派技法直接接入运行时。它只把“宾主、体用、做功、原神目标神、作用路径”拆成可审阅、可转为条件模型的中性对象。

## 通用条件轴

- `source_layer`：本命、宫位、藏干、时间层、象法归档层。
- `actor`：作用发起方，如某十神、某干支、某宫位。
- `receiver`：作用承受方或目标神。
- `action_path`：生、克、合、冲、刑、害、破、制、化、入库、出库等路径。
- `capacity_strength`：发起方与承受方的强弱、根气、透藏、承载。
- `same_layer_action`：作用是否发生在同一层，跨层只能记为背景或引动。
- `result_boundary`：只说明结构作用，不输出富贵贫贱、财富、婚恋、健康或应期。

## 第一批对象

| 对象 | 结构含义 | 安全边界 |
|---|---|---|
| 宾主定位 | 区分结构中的主体、客体和作用方向 | 不直接判断谁得谁失 |
| 体用定位 | 区分自身承载与外部可用对象 | 不直接判断用神忌神 |
| 原神目标神 | 标记作用路径起点和目标 | 不直接判断结果成败 |
| 做功路径 | 记录实际发生作用的路径候选 | 不能只凭同见判作用 |
| 做功效率 | 结合强弱、通关、阻隔看作用强度 | 不输出成败结论 |
| 合冲做功 | 合、冲作为作用路径或引动路径 | 关系名不等于作用成立 |
| 制化做功 | 制、化、通关、转化路径 | 必须检查同层与承载 |
| 墓库做功 | 入库、开库、库中藏物参与作用 | 不输出库财库官断语 |
| 宫位做功 | 宫位作为作用发生位置和承载层 | 不直接断六亲领域结果 |
| 十神做功 | 十神之间形成实际生克制化路径 | 不把十神名直接等同事件 |
| 时间引动作功 | 大运流年触发本命已有路径 | 时间层不改写本命结构 |
| 换象带象 | 象法归档中的转义和携带信号 | 只作中性标签，不作断语 |
