# 盲派理法知识单元 v1

状态：P31A 基础目录补齐。

## 治理边界

盲派理法先只进入结构化标签，不进入断语。宾主、体用、做功、原神、目标神都用于描述结构中的作用方向、主体、目标和路径，不直接判断富贵贫贱、事业财富、婚姻健康或应期。

## 第一批主题

| 主题 | 当前定位 | 风险 |
|---|---|---|
| 宾主 | 作用方向与角色归因 | R2 |
| 体用 | 主体与对象分层 | R2 |
| 做功 | 作用路径候选 | R2 |
| 做功效率 | 强弱与路径共同审核 | R3 |
| 原神 / 目标神 | 路径端点元数据 | R3 |

## 规则化边界

- 必须有 `source_layer`、`actor`、`receiver`、`action_path`。
- 必须与强弱、宫位、十神或时间层建立可解释连接。
- 不允许直接输出盲派口诀式断语。
