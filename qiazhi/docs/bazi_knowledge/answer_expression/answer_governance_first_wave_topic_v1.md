# 回答表达与治理第一批专题 v1

状态：P38 新知识审阅目录

## 定位

P38 补 L11 回答表达与治理。它不新增命理事实，只规定知识如何安全进入回答、Review UI 和 Rule DB 门禁。

## 第一批对象

| 对象 | 作用 | 安全边界 |
|---|---|---|
| 结构说人话 | 把结构事实翻译成普通中文 | 不输出内部字段 |
| 不支持问题降级 | 把系统不能回答的问题降级到结构问题 | 不硬答 |
| 内部术语过滤 | 过滤 rule_id、signal_id 等内部词 | 不暴露系统实现 |
| 预测断语过滤 | 过滤必然、发财、破财、疾病、应期等断语 | 不输出预测 |
| 证据边界表达 | 说明证据来源和不足 | 不把证据当结论 |
| 时间层表达 | 说明大运流年触发关系 | 不说事件预测 |
| 领域安全降级 | 财富事业关系健康等领域按风险降级 | 不输出领域结论 |
| 反馈表达优化 | 用户反馈只优化表达和推荐 | 不改命理规则 |
| 失败归因展示 | Review UI 展示推荐/知识/规则/表达归因 | 不自动批准 |
| draft 提案展示 | 展示知识 seed、rule draft、answer expression | 不自动启用 |
| 合成评估报告 | 展示正反样本和误触发 | 不替代规则事实 |
| 智能门禁报告 | 展示选中、阻断和原因 | 不跳过回归 |
| 回滚谱系 | 记录版本、来源和回滚路径 | 不隐藏变更 |
| 自动审批边界 | 低风险可候选，高风险必须阻断或人工复核 | 不自动上线 |
