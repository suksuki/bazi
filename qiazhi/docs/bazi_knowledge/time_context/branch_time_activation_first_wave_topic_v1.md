# 地支关系与时间引动第一批专题 v1

状态：P35 新知识审阅目录

## 定位

P35 补地支关系、天干关系、墓库和时间引动的细化知识。它解决两个问题：

- 结构层：关系名不能直接等于作用成立，例如三合、三会、六合、六冲、刑害破、墓库开闭都需要条件。
- 时间层：大运流年只能触发、显化或加重本命已有结构，不能改写本命。

## 通用条件轴

- `relation_name`：关系名，如合、冲、刑、害、破、三合、三会、墓库。
- `source_layer`：本命、大运、流年、藏干、宫位。
- `same_layer_action`：是否同层发生作用，跨层只作引动或背景。
- `target_object`：被引动的是天干、地支、藏干、十神、宫位、墓库还是格局候选。
- `open_close_condition`：墓库或合冲是否形成打开、闭合、合住、冲动。
- `capacity_strength`：关系双方和目标对象是否有力。
- `answer_boundary`：只说明结构被触发，不输出事件预测或应期。

## 第一批对象

| 对象 | 结构含义 | 安全边界 |
|---|---|---|
| 六合 | 两支形成合的关系候选 | 合名不等于合化 |
| 六冲 | 两支形成冲的扰动候选 | 冲名不等于结果发生 |
| 三合局 | 三支成局或半合拱合候选 | 必须区分半合、全局、拱合 |
| 三会局 | 三支会方、季节成势候选 | 必须看月令与会方完整度 |
| 地支刑 | 刑作为结构压力或互扰候选 | 不直接断灾 |
| 地支害 | 害作为隐性牵制候选 | 不直接断损害 |
| 地支破 | 破作为结构松动候选 | 不直接断破败 |
| 天干五合 | 两干相合、牵制或合化候选 | 合而不化要单列 |
| 天干冲克 | 天干同层克制或冲突候选 | 不输出好坏 |
| 墓库开闭 | 库位打开、闭合、藏物可见候选 | 不输出库财库官 |
| 藏干引动 | 藏干因冲合刑害等变得可见 | 背景藏干不升主机制 |
| 大运引动本命 | 大运触发本命已有结构 | 不改写本命 |
| 流年引动本命 | 流年短期触发本命结构 | 不直接预测事件 |
| 流年引动大运 | 岁运之间形成触发或牵制 | 必须标明岁运层级 |
| 干支同动 | 时间天干地支同时触发对象 | 需拆干、支两条证据 |
| 十神引动 | 时间层让某十神可见或被触发 | 不直接转领域结论 |
| 宫位引动 | 时间层触发某柱或宫位 | 不直接断六亲领域 |
| 墓库引动 | 时间层触发墓库开闭或藏物 | 不直接断应期 |

## 规则化边界

- 关系名不能直接等于作用成立。
- 时间层不改写本命结构，只能作为背景、触发或引动。
- 不输出应期、事件预测、财富、婚恋、健康或职业结论。
