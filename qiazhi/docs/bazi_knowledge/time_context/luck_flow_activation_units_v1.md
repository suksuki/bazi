# 大运流年引动知识单元 v1

状态：总目录占位 + 命理师审阅目录

范围：记录大运、流年如何触发、显化、冲合、牵制或提示本命结构。引动只说明“哪个结构被时间层看见或触发”，不直接等同事件预测。

## 为什么需要单独目录

“大运流年引动”比普通时间背景更具体。时间背景只回答“这是大运还是流年”，引动要回答：

- 引动的是哪一柱、哪一个天干或地支？
- 是天干引动、地支引动，还是干支同动？
- 是冲、合、刑、害、破、三合、三会，还是墓库触发？
- 引动的是十神、财星、官杀、印星、食伤，还是宫位？
- 引动发生在本命、大运、流年之间的哪一层？

## 规则化边界

| 层级 | 内容 | 风险 |
|---|---|---|
| 引动存在 | 说明哪一层触发哪一结构 | R1 |
| 引动机制 | 说明冲合刑害破、墓库、透藏如何作用 | R2 |
| 引动结果 | 说收入、事业、婚姻等结果改变 | R3 |
| 应期断事 | 说某年必发生具体事件 | R4 |

## 审阅边界

- 可以说“流年地支与本命日支形成冲，日支相关结构被触发”。
- 可以说“大运天干让某个十神从背景变为可见”。
- 可以说“墓库被时间层关系引动，需要看开闭、合冲、藏干和宫位”。
- 不可以直接说“这一年一定破财 / 升官 / 结婚 / 生病”。
