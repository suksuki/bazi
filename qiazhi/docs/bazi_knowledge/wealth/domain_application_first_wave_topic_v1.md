# 领域应用承接第一批专题 v1

状态：P36 新知识审阅目录

## 定位

P36 补 L8 领域应用知识。它不做领域预测，而是定义领域层如何承接上游结构信号。

领域层只能接收这些已经归因的信号：

- 十神结构：财、官杀、印、食伤、比劫等。
- 强弱承载：日主是否能承载某类资源或压力。
- 格局候选：只作为领域解释背景，不直接输出成败。
- 宫位位置：只说明结构落点，不直接判断六亲或婚恋。
- 时间引动：只说明触发，不输出事件或应期。

## 通用条件轴

- `domain_name`：财富、事业、关系、健康、六亲、子女、性格等。
- `upstream_signal`：领域承接的上游结构信号。
- `source_layer`：本命、宫位、时间层、归档层。
- `capacity_strength`：承载、可达性、根气、强弱。
- `domain_boundary`：领域层禁止直接输出的内容。
- `answer_downgrade`：高风险领域必须降级为结构说明或安全提示。

## 第一批对象

| 对象 | 结构含义 | 安全边界 |
|---|---|---|
| 财富收入结构 | 财星、食伤、比劫、承载共同进入财富语境 | 不断收入高低 |
| 财星显隐可达 | 财星是否可见、可达、被阻隔 | 不等于赚钱结果 |
| 财富稳定波动 | 财库、合冲、比劫、时间层共同影响稳定性语境 | 不断发财破财 |
| 食伤变现路径 | 输出连接财星的资源转化候选 | 不断职业或收入 |
| 比劫资源分配 | 同类竞争、合作和分配语境 | 不断破财 |
| 事业官杀语境 | 官杀作为规则、压力、组织结构候选 | 不断职位权力 |
| 事业产出资源路径 | 食伤、财、印等承接事业表达 | 不断成功失败 |
| 格局事业承接 | 格局候选进入事业前必须过质量边界 | 不以格局断职业 |
| 关系日支语境 | 日支作为贴身位置和关系承载 | 不断婚姻好坏 |
| 关系十神语境 | 财官等十神作为关系来源层 | 不断对象质量 |
| 健康安全归档 | 健康只作传统资料归档和安全降级 | 不断疾病寿命 |
| 六亲来源层 | 柱位、宫位、十神作为六亲来源 | 不断家庭结果 |
| 子女来源层 | 时柱、食伤作为来源层 | 不断子女数量好坏 |
| 性格象意归档 | 象意只作中性标签 | 不做人格定性 |
