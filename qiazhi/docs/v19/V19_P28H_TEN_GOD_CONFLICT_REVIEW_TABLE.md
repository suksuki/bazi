## 快路径候选

这些对象可以优先进入“低风险组合存在”候选，但只允许输出结构元数据，不允许输出机制结论：

| 对象 | 可规则化部分 | 仍需禁止 |
|---|---|---|
| 伤官见官 | 只确认伤官与正官同见 | 官非、灾祸、事业不顺 |
| 比劫分财 | 只确认比劫与财星同见 | 破财、损失、收入变化 |
| 食伤混杂 | 只确认食神与伤官同见 | 性格、才华、职业结论 |
| 印枭混杂 | 只确认正印与偏印同见 | 学业、长辈、健康结论 |

## 条件模型待补

这些对象不能直接进入启用规则，只能保留 Rule DB 候选：

| 对象 | 暂缓原因 |

| 伤官制杀 | 需要伤官强弱、七杀压力、日主承载和印星介入模型 |
| 食神制杀 | 需要食神是否有力、七杀是否成压、承载与财印路径 |

| 比劫夺财 | 需要财星可达性、比劫强弱、官杀制比劫 |
| 财破印 | 需要财星强弱、印星角色、是否有比劫或官杀改路径 |
| 财多坏印 | 需要财星数量、根气、可达性和印星关键性 |
| 财滋杀 | 需要财星是否有力、七杀压力、食伤制杀或印化杀 |
