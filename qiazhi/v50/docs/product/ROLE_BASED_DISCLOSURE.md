# Role-based Disclosure

角色只控制信息密度、语言和可执行动作，不产生新的命理结论。同一个 `LifeCase` 是唯一认知来源。

## 普通用户

默认看到：整盘结论、简明依据、当前时间位置、不确定性、下一步与所选专题的现实含义。

默认隐藏：内部 ID、完整 Hypothesis Space、原始 Graph、规则来源、专业候选比较和研究状态。

## 命理师

在普通用户结果之上展开：竞争假设、主做功、条件用忌、领域断言、支持与反证、Probe 目的和专业解释路径。

命理师选择只更新当前案例的专业审阅状态，不修改命盘事实、全局理论或系统权重。

## 研究者

进一步展开：事实与知识引用、候选路径、验证状态、反例、异常、理论缺口和贡献入口。

研究贡献必须进入独立研究审核链，不能直接成为生产结论。

## Admin

Admin 可以切换披露视图以测试各角色体验。切换视图不重算命盘、不产生新洞察，也不改变账户的案例数据。

## 强制不变量

```text
One Life Case
→ Different Disclosure
≠ Different Mingli Cognition
```
