## 1. Current Product

DeepBazi is a Mingli-first intelligent product, not a generic coach and not a static report generator.

The core user experience is:

```text
establish a valid chart
→ receive a chart-specific baseline cognition
→ explore one question at a time
→ understand structure, conditions and uncertainty
→ verify against reality
→ preserve the evolving LifeCase
```

Abu guides, explains, speaks, and operates approved product actions. Pages display the current case state and task. Neither page templates nor Abu dialogue may substitute for real chart cognition.

## 8. Product Non-Goals

- longer static reports as a substitute for intelligence;
- a generic free-form chatbot;
- deterministic modules pretending to be the whole-chart Mingli brain;
- arbitrary fortune scores;
- concrete medical, financial, or guaranteed-event predictions;
- exposing engineering, ontology, or debug information to ordinary users;
- multiplying pages for every domain or technical lens;
- making Abu repeat the same action already owned by the page.
