# V50 Mission and Intelligence Definition

Status: canonical north star

## Mission

DeepBazi is a professional Mingli cognition and life-understanding platform guided by Abu.

```text
先真正理解命局
→ 再理解人生领域与当前时机
→ 再帮助用户形成更清楚的行动判断
```

Public promise:

> 看见人生的结构，理解当下的时机。

Research mission:

> 让命理从经验走向可计算，从可计算走向可验证，从可验证走向可演化。

## What V50 Is

V50 is not a template report generator, a deterministic rule judge, a generic chatbot, or an LLM expression layer.

It is a world-grounded, tool-augmented and evidence-constrained Mingli cognitive system.

```text
Mingli World Model
→ Chart World Instance
→ Context Compiler and tools
→ LLM Cognitive Agent
→ Assertions and competing hypotheses
→ Epistemic Review
→ Case Memory, Probe and Abu delivery
```

## What Intelligence Means

V50 intelligence has six observable abilities.

1. **Attention**: identify what deserves priority in the chart.
2. **Pattern discovery**: form a coherent whole-chart structure instead of listing parts.
3. **Hypothesis competition**: compare plausible readings and explain why one currently leads.
4. **Domain inference**: derive career, wealth, relationship, health and other life-domain assertions from the whole chart.
5. **Revision**: use evidence, timing and Probe feedback to revise the current case without corrupting natal facts or global theory.
6. **Uncertainty**: state what is known, conditional, weakly supported or still unknown.

Fluent prose, schema compliance and a confidence number are not intelligence by themselves.

## Core Assets

DeepBazi's durable assets are:

- curated Mingli knowledge and theory;
- verified chart facts and deterministic tools;
- Pattern Discovery and hypothesis-comparison protocols;
- synthetic, historical, counter and case evidence;
- professional case memory and correction history;
- evaluation sets that distinguish real cognition from templates.

Models may change. These assets make stronger models useful and replaceable.

## Product Experiences

The same cognitive record supports different authorized tasks.

- **Guest**: receive one useful, bounded recognition before registration.
- **Member**: understand self, timing, uncertainty and next action.
- **Practitioner**: inspect structure, competing hypotheses, work path, evidence, counter-evidence and client explanation.
- **Research Master**: audit theory, submit counterexamples and contribute evidence.

These are role-aware views of one cognition, not four judgment engines. Admin may preview roles for testing; other accounts see only authorized depth.

## Abu

Abu is the guided interface to the system. Abu may collect birth information, clarify intent, explain an accepted result, ask the next useful Probe, navigate the workspace and summarize changes.

Abu does not invent chart facts, silently change hypotheses, bypass review or pretend unsupported domains are known.

## Research Loop

```text
Question
→ research hypothesis
→ evidence and counterexamples
→ formalization
→ controlled validation
→ explicit promotion
→ case use
→ new observations
```

Case reasoning and global theory evolution are related but separate. A persuasive reading is not automatically a new theory.

## Training

Training is one optional calibration mechanism, not the learning loop itself. V50 also improves through better facts, knowledge retrieval, pattern attention, case benchmarks, tool use, context compilation and review.

Never call a background script or local-LLM validation run “training” unless weights or an explicitly trainable policy are actually modified.

## North Star Gate

Before adding a module, rule, prompt, page or animation, ask:

1. Does it improve professional chart understanding?
2. Does it improve evidence, revision or uncertainty?
3. Does it help a real user or practitioner complete a meaningful task?
4. Can we verify the improvement without rewarding templates?

If not, it is not current mainline work.

## Final Principle

> DeepBazi's goal is not to produce more Mingli text. It is to build an AI Mingli cognition that can observe, hypothesize, reason, be reviewed and revise itself responsibly.
