# SIX-01 Six-pillar Relation Semantics Audit v1

Status: `FOUNDATION_AUDIT_COMPLETE_WITH_OPEN_SEMANTICS`

SIX-01 is a read-only audit of the current deterministic relation engine. It does
not add relation rules, alter formal assertions, or use an LLM. The reproducible
machine-readable matrix is generated by:

```bash
PYTHONPATH=packages:apps:tests:. python scripts/v50_audit_six01_relation_semantics.py \
  --output reports/v50-next-framework-alignment/six01_relation_semantics_v1.json
```

The current matrix covers 100 ordered stem pairs, 78 unordered branch pairs
including repeats, 120 stem-to-branch pairs, 36 ordered six-slot identity pairs,
13 runtime relation types, six implemented n-ary relations, and four research-only
three-meeting candidates. Its deterministic content SHA-256 is:

```text
f79c9d248ba9f7b57b61c35103ff38eb1b3118b957564a2160f1cd50f6da1370
```

Fixtures: 14 positive, 7 negative, and 5 boundary cases. They prove current
behavior only; they are not a second runtime authority.

## Verified boundary

- Structural existence is not temporal activation.
- Combination existence is not successful transformation.
- Candidate relations cannot be promoted by the client or Lab.
- Natal, luck, and annual nodes retain distinct stable identities.
- Multiple structural relations on the same branch pair remain visible.
- Fixed legacy strengths are compatibility values, not calibrated measurements.

## Open semantics

1. Stem five-combination conditions are not formalized.
2. Stem clashes remain school-dependent and unfrozen.
3. Three-meeting structures are not implemented.
4. Combination and transformation lack separate validated contracts.
5. Cross-level stem/branch action is only partially qualified.
6. Month command, adjacency, distance, and position priority are undefined.
7. Structural relation and temporal activation lack one trigger contract.
8. Simultaneous relation coexistence and priority are undefined.
9. Relation strength is not calibrated.

These gaps are the input to later relation research. SIX-01 does not silently
fill them and does not claim the six-pillar algorithm is complete.
