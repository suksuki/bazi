# VNext Cognitive Refoundation Large-cycle Roadmap v1

Status: `active strategic baseline`

## Mission

DeepBazi 不再用确定性模块模拟一个弱化的命理师大脑。系统负责建立可信的命理世界、工具、记忆与审查环境；经过验证的 LLM Cognitive Model Policy 负责整盘综合推理。

```text
Immutable Chart Facts
-> Independent First Look
-> Pattern / Hypothesis Space
-> Tool and Counter-evidence Challenge
-> Comparative LLM Reasoning
-> Whole-chart Cognition
-> Domain Causal Reasoning
-> Typed Assertion Graph
-> Epistemic Review
-> Case Memory
-> Predictive Probe
-> Role Projection
-> Abu Experience
```

本路线以“恢复并证明专业命理认知”为第一目标。产品体验、Abu、Discovery Lab 和训练都必须服从这个证据顺序。

## Frozen Cognitive Authority

| Authority | Owns | Does not own |
| --- | --- | --- |
| Validated LLM Cognitive Model Policy | 整盘重心、竞争假设、主次做功、条件性用忌、领域因果、先验断言、鉴别问题 | 历法计算、命盘事实、理论治理、生产权限 |
| Mingli World Model | 不可变事实、理论条件、案例、反例、结构关系、工具结果 | 最终整盘判断 |
| Reasoning Orchestrator | 任务分阶段、最小充分上下文、工具可见性、状态和调用顺序 | 替 LLM 下断 |
| Epistemic Review | 事实检查、证据追溯、反证检查、局部确定性修复、越界阻断 | 重写成保守模板、创造新断语 |
| Human Expert Governance | 理论准入、专家参考、争议保留、基准裁决 | 直接污染命盘事实或全局运行规则 |
| Case Feedback | 当前案例 Belief、断言支持度和局部修正 | 修改原局事实、自动修改理论或全局策略 |
| Abu | 引导、解释、澄清、呈现下一步 | 独立命理裁决 |

## Epochs

### Epoch 0 - Cognitive Authority Stabilization

目标：用固定命盘、统一合同和盲审证明新认知链的增量价值。

当前状态：`Phase 0 harness usable; professional cognition unproven`。

Epoch 0 拆为三个不可跳过的门禁：

```text
P0-G1  Expert Reference / Frontier Policy / Formal Lock
P0-G2  Formal 10 x 6 x 3 immutable blind run
P0-G3  Expert adjudication and architecture promotion decision
```

已用于 Dry Run 的命盘属于 Development Set，不得进入 P0-G2。模型政策选择使用独立 Selection Set；正式十盘与两者均不得重叠。

交付：

- 六路认知基准；
- 三次重复稳定性；
- 先验与受控反馈两轮协议；
- Graph / Path / Role / Ablation 权威降级；
- Discovery Archaeology 只读资产清单；
- 人工盲审包与 Lane 映射隔离。
- Development / Model Selection / Sealed Formal 三套互斥清单；
- Round 1 Expert Reference Space 与 Round 2 Reality Evidence 分离；
- Prompt、Context、模型、预算、失败策略、Review 和门槛的 FormalRunLock。

退出门槛：

- VNext 明显优于 Current V50；
- 相对 Holistic Synthesis Baseline 证明 VNext 编排、工具挑战与 Review 的真实增量；
- 相比 Direct Same Model 有可说明的系统增量；
- 若有真实 Frontier Lane，相比直接问最强模型仍有结构、稳定性、证据或记忆增量；
- 不依赖现实经历完成第一份先验判断；
- 不出现大面积跨盘模板化；
- 实验工具关闭后仍能完成基本整盘判断。
- 正式结果产生前已冻结 Go / No-Go 门槛，运行后不得改口径。

### Epoch 1 - World Model and Context Quality

目标：只修被 Epoch 0 证据确认的事实、知识检索、上下文或工具缺口。

重点：

- Immutable facts 完整性；
- Pattern attention coverage；
- 最小充分 Context；
- 知识条件与反例检索；
- 工具输出的认识论标签；
- 历史 V30 仅在真实资产可复现时做选择性方法与案例迁移，不作为正式实验硬门禁。

禁止：以新模块数量代替认知增量。

### Epoch 2 - Comparative Reasoning and Review

目标：让 LLM 稳定比较真实竞争假设，而不是生成一个主结论和一个陪衬。

重点：

- 假设生成、消融和竞争；
- 做功因果闭合；
- 条件性用神与忌神；
- falsifier 与先验预测；
- Review 的局部修复与同行评审语义；
- 模型、Context、参数、Schema、Review 的联合 Policy 基准。

### Epoch 3 - Case Learning and Predictive Probe

目标：反馈只更新当前案例，并证明系统能局部修正而不自我圆回。

重点：

- Case Belief State；
- 数字年份、具体事件和行为模式的鉴别性 Probe；
- 信息增益排序；
- 未受影响断言保持；
- Practitioner / Research 结构化校准；
- 真实反馈 Intake 与隐私边界。

### Epoch 4 - Product Projection and Abu Experience

目标：同一专业认知按 Guest、Member、Practitioner、Research 任务投影，Abu 成为受控交互入口。

重点：

- 分段生成与流式认知预览；
- 角色密度与权限；
- Abu 指令注册、确认与恢复；
- 任务画布、案例工作台和研究审计；
- 用户价值与命理深度盲测。

### Epoch 5 - Discovery Lab

目标：在生产认知恢复后，让 518K 结构宇宙用于异常、聚类、受控变体和理论候选发现。

重点：

- 结构分布、奇点候选与相似盘检索；
- Graph / Path 工具校准；
- 能量断裂与特殊年份候选；
- 从观察到 Theory 的 L0-L6 生命周期；
- 研究与生产权限隔离。

`518K` 不具有现实结果标签，不得直接训练“结构 -> 职业/财富/性格”的结论。

### Epoch 6 - Training and Promotion

目标：只训练已经通过专家基准、真实反馈和反例验证的可训练对象。

可训练对象包括：

- Context selection policy；
- Pattern attention ranking；
- Probe information-gain policy；
- Model/parameter routing；
- Review and deterministic repair；
- 表达层与多语言。

Theory 和命理结论不能由训练数据自动冻结。任何生产 Promotion 必须独立授权。

## Measurement Model

每日不再用 `Next Task` 衡量推进，而使用：

```text
Yesterday's Discovery
Current Bottleneck
Evidence Delta
Unknowns
Decision Intelligence Impact
```

跨 Epoch 的共同 KPI：

- factual correctness；
- salience / pattern recognition；
- hypothesis quality；
- causal closure；
- conditionality；
- falsifiability；
- cross-chart distinction；
- repeat stability；
- local revision quality；
- expert usefulness；
- user recognition and decision clarity。

## Non-negotiable Boundaries

1. 不用输出 Schema 完整度冒充专业正确。
2. 不用自动分数冒充命理师盲审。
3. 不把 synthetic expected contract 喂给模型。
4. 不把 518K 结构分布当现实结果证据。
5. 不把实验工具输出伪装为事实。
6. 不让 Review 把专业内容洗成模板。
7. 不让 Probe 提供本应在先验阶段给出的答案。
8. 不把用户反馈升级为全局理论。
9. 不绑定单一模型；生产主体是完整的 Validated Cognitive Model Policy。
10. 没有基准证据，不训练、不改权重、不自动 Promotion。
