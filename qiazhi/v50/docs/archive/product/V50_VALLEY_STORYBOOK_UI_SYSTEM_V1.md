# V50 Valley Storybook UI System v1

## Direction

DeepBazi should feel like entering a quiet hand-painted valley with an intelligent guide, not opening a dashboard or reading a generated PDF.

The visual language uses original DeepBazi assets and broad storybook-animation qualities:

```text
hand-painted nature
quiet morning light
soft paper and ink
small living motion
precise editorial hierarchy
```

It does not imitate a specific film, scene, or character design.

## Product Composition

```text
Topbar       = identity and current chart
Abu Pane     = living guidance and conversation
Reading Pane = calm task canvas
```

The reading pane owns conclusions and professional work. Abu owns explanation, transitions, and the next question.

## Palette

Warm paper is a surface, not the entire palette. Mist, sky, pine, sunlight, and coral keep the product from becoming a one-note beige interface.

## Typography

```text
Display: Songti SC / Noto Serif CJK SC / serif
UI:      PingFang SC / Noto Sans CJK SC / system sans
```

Rules:

- Chinese display titles use weight 600.
- Long chart judgments remain body-scale, never poster-scale.
- No visible heading exceeds 48px.
- Body text stays between 15px and 17px with generous line height.
- Labels are quiet and short; no letter spacing tricks.

## Signature Details

1. Abu stands in a shallow painted-valley strip rather than a generic app header.
2. Active reading tabs use a small sunlight dot and a coral underline.
3. Evidence revisions look like field notes, not alert boxes.
4. Pillars use restrained seal-like blocks.
5. Domain and professional choices remain scan-friendly lists instead of card piles.
6. Motion is limited to breathing, blinking, small lift, and mist-like transition timing.

## Responsive Intent

Desktop keeps Abu and the reading canvas visible together. Mobile switches between them while preserving the same journey state. Professional stage navigation scrolls horizontally with stable dimensions; content never shrinks into unreadable columns.
