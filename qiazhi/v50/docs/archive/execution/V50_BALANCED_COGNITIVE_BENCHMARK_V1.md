# V50 Balanced Cognitive Benchmark v1

Status: active validation authority

## Why

Repeated success on one bridge chart does not establish general Mingli
cognition. The benchmark must measure structure classes, controlled differences
and unseen cases separately.

## Corpus layers

```text
Structural Population
  deterministic full-distribution tools and 17 taxonomy classes

Cognitive Development Set
  visible during prompt and contract development

Blind Holdout Set
  excluded from prompt-specific tuning

Metamorphic Set
  one controlled chart change with explicit change/preservation expectations

Expert Gold Set
  human-reviewed whole-chart cognition and counter-evidence
```

## Current 17 structural strata

month command, bridge, converter, day anchor, hidden line,

output-controls-pressure, mixed officer/killing, resource-disrupts-output,

## Cognitive metrics

```text
pattern candidate coverage

overconfidence violations
cross-chart semantic diversity
probe discrimination quality
expert blind preference
latency by stage
```

Schema pass is necessary but never sufficient.

## Anti-overfit rules

1. A single failing chart cannot authorize a prompt or rule patch.
2. Every repair is classified as case-local, stratum-level or global.
3. Holdout case content cannot enter prompts or expert priors.
4. Promotion requires improvement across strata without regression on
   metamorphic preservation checks.
5. Synthetic expected contracts state why an expectation exists and its
   evidence basis.

## Live cadence

The full 17-class deterministic lane runs on every architecture change. Live LLM
evaluation uses a rotating stratified subset; the blind holdout rotates only at
a declared benchmark version boundary. No self-generated text is promoted to
training data without expert review.
