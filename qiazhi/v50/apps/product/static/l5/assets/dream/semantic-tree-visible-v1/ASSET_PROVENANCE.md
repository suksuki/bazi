## Production method

- `tree_base_clean.png` is a non-destructive generative edit of the authoritative current fixed-tree composition. Only the old large Abu region was removed and reconstructed as forest ground; no semantic organ or character is baked into the base.
- Leaf, trunk, flower, fruit, and occlusion layers were generated as independent chroma-key sources, locally converted to Alpha, trimmed, scaled, and visually inspected.
- Hit masks were generated from each final Alpha silhouette and dilated for practical touch targets.
- `energy_flow_mask` is a deterministic full-canvas mask authored against the final tree geometry. It does not contain business state.
- The formal Abu files are copied unchanged from `ABU_CHARACTER_V1`.


approval before Runtime integration.
