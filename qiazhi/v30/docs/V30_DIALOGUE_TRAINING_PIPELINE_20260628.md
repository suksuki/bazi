# V30 智能对话训练与验证管线

更新时间：2026-06-28

## 目标

这份文档合并 DTC-1 到 DTC-8 的阶段性记录，作为 V30 智能对话系统的训练、候选策略、验证、人工复核与重型验证执行计划的主文档。

核心边界：

- 训练链路必须服务八字测算主线，不做脱离命盘证据的闲聊系统。
- 所有训练、候选、验证、复核默认只读，不直接修改生产策略。
- 策略晋级必须经过候选生成、离线验证、人工复核、重型验证、显式发布。
- 任何 fallback 文案都不能冒充 LLM 或中枢智能大脑推演结果。

## 当前链路

### DTC-1：对话训练校准循环

输入运行时对话轨迹、用户问题、答案、上下文证据，生成训练样本与策略候选。该阶段只做样本归档与候选提取，不改变线上问题策略。

产物：

- 训练样本
- 候选问题策略
- 证据绑定摘要
- 风险标签

### DTC-2：策略候选复核

把候选策略编译为可比较的 question policy payload，并生成策略差异报告。该阶段用于确认候选是否具体、是否绑定命盘证据、是否改善问题推荐。

产物：

- 策略候选 payload
- 当前策略与候选策略对比
- 可读复核报告

### DTC-3：策略验证闸门

读取 DTC-2 的对比产物，检查候选策略是否真的带来可衡量变化。只有通过闸门的候选才允许进入合成回放队列。

验证重点：

- 推荐问题是否更贴合当前八字页面
- 是否减少空泛、重复、无上下文问题
- 是否保持结构化证据绑定
- 是否不越权写入生产策略

### DTC-4：合成回放队列

使用多场景合成样本回放候选策略，验证它在不同命盘、不同页面、不同用户意图下是否稳定。当前批次覆盖 4 个代表性场景，并已通过离线回放。

场景类型：

- 事业方向
- 财务节奏
- 关系模式
- 隐藏属性线索校准

### DTC-5：人工复核包

把 DTC-1 到 DTC-4 的产物整理为人工复核包。该阶段不自动发布，只给操作者一个明确、可审计的判断材料。

复核内容：

- 候选策略变化摘要
- 合成回放通过情况
- 已知风险
- 建议动作
- 禁止动作

### DTC-6：重型验证决策

根据人工复核包，给出是否进入重型验证的建议。当前建议进入两个验证门：

- `dialogue_synthetic_all`
- `dialogue_518k_sample`

该阶段只产生决策建议，不执行验证命令。

### DTC-7：重型验证授权

记录允许执行 DTC-6 推荐的重型验证门。授权仍然不等于执行，不写策略指针、不发布、不修改命盘事实。

授权边界：

- 只允许执行已列明验证门
- 不允许自动晋级生产策略
- 不允许隐式修改训练样本
- 不允许把验证失败包装为通过

### DTC-8：重型验证执行计划

将授权转换成可执行命令计划，但仍然不直接执行。

计划命令：

```bash
python3 scripts/run_synthetic_validation.py --tier all
python3 scripts/run_518k_validation.py --mode sample --limit 8
```

执行要求：

- 命令结果必须保存为可审计 artifact。
- 失败必须保留失败原因和最小复现上下文。
- 通过后仍需显式发布步骤，不能自动上线。

## 当前禁止事项

- 不写入 production policy pointer。
- 不自动 apply 候选策略。
- 不修改八字排盘、规则、画像、路径等事实层数据。
- 不用模板或兜底文案冒充中枢智能大脑结论。
- 不在页面上幽灵式弹出问题；问题必须由页面阶段、证据缺口和用户意图触发。

## 下一步主线

DTC-9：显式执行 runner。

目标是把 DTC-8 的执行计划变成受控命令入口，要求：

- 明确输入验证门。
- 统一保存执行日志和 artifacts。
- 给出通过、失败、阻断三态结果。
- 结果只能进入复核区，不能直接发布。
