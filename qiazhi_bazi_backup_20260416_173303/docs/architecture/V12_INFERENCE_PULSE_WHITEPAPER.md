## 0. 执行摘要

**Inference-Pulse** 定义下一代 Qiazhi 大脑的运行论：**中枢持续感知物理张量的波动**（Pulse），在法典与裁决偏置约束下，**自主发起逻辑追问与冲突审计**；大模型退居**语音层**，不得僭越物理真值与法典准则。本文与 M1 中的 **Logic Interrupter**、**Arbiter_Bias** 契约同构，M1 负责数据与载荷形状，本文负责**权力边界与算子语义**。

---

## 1. 核心哲学：从「管道」到「中枢」

### 1.1 现状（管道模型）

- 主路径近似 **线性**：输入 → L0/L1 物理 → L2 法典与插件 →（可选）组装上下文 → LLM 总结。
- 缺陷：系统对「张量是否在敏感区间波动」「法典置信是否不足」「用户是否尚未对关键碰撞表态」**缺乏统一的、可编排的反应**；追问多依赖前端或人工，**中枢缺少脉冲式自治权**。

### 1.2 目标（中枢 + 脉冲）

- **Brain Hub** 作为常驻逻辑核心：**订阅**物理与推演状态的变化（非仅单次请求尾部调用 LLM）。
- 中枢具备三类能力（后文算子展开）：
  1. **校验**：语义是否与物理/法典取向冲突 → 拒稿与重写门控。  
  2. **追问**：关键逻辑点置信不足 → **系统发起**用户交互，回答**结构化写入** `Arbiter_Bias`。  
  3. **断言治理**：确定性结论由系统从法典树挂载；LLM 只缝合模糊带。

> **脉冲（Pulse）**：一次可观测的状态变化（例如某轴能量越阈、L2 某 `pattern_id` 亲和骤降、意志切换导致门控翻转）触发中枢内一次**决策节拍**，决定是否中断、是否追问、是否放行叙事。

## 2. 三权分立模型（Tri-Sovereignty Model）

三权不是三个服务名，而是**裁决优先级**与**写权限**的宪法；任何实现须可通过审计日志还原「谁说了算」。

| 主权 | 代号 | 持有者 | 唯一性声明 | LLM 边界 |
|------|------|--------|------------|----------|
| **物理主权** | The Bone | L0/L1 产出的张量与可复算基线 | **场上能量与相互作用结论的唯一真理来源**（在既定参数版本下） | 不得编造、改写数值事实；不得用叙事覆盖张量符号 |
| **法典主权** | The Law | L2（Manifest 引擎）与注册插件的结构化判定 | **格局/红线/门控类准则的唯一准绳**；排序与排除以法典轨迹为准 | 可复述与润色，但**不得**在无证典锚点下宣布「破格/成格」终局 |
| **语义辅助** | The Voice | 大模型 | **逻辑翻译官**与**情感缝合师**：在 Bone + Law 已给定的边界内组织自然语言 | **严禁**绕过物理事实自行定论；**严禁**以「文学吉凶」对抗张量趋势与法典排除结果 |

### 2.1 冲突时的优先级

1. 若 Voice 与 Bone 在**规范中间表示**上冲突 → **Bone 胜**；触发 **Logic Integrity Guard**（见 §3.A）。  
2. 若 Voice 与 Law 在**格局定性**上冲突 → **Law 胜**；允许仅保留 Voice 中**不矛盾**的修辞层。  
3. 若 Bone 与 Law 在实现上因版本/数据不一致产生矛盾 → **中枢进入审计态**（人工或规则优先级表，**不由 LLM 仲裁**）。

## 3. 核心智能算子（Intelligence Operators）

以下算子为**架构能力**，具体阈值、解析器与队列实现由后续模块定义；**M1** 已为 **追问** 提供 `Logic Interrupter` 与 `Arbiter_Bias.bias_ack_tokens` 协议槽位。

### 3.A 逻辑真值校验层（Logic Integrity Guard）

| 项目 | 说明 |
|------|------|
| **功能** | 在叙事落档前，将 **LLM 输出的规范取向**（如结构化吉凶标签、断言极性、与物理摘要同构的符号向量）与 **物理能量趋势摘要**（由 Bone 导出，非原始浮点 dump）做**自动对撞**。 |
| **硬性约束** | 若检测到 **物理侧符号为衰减/风险取向** 而 **叙事侧为增长/大吉取向**（或等价矛盾），执行 **拒稿（Reject）**：禁止该版本进入 `verdict_anchor_layer` 主展示；触发 **重写**：由系统带**异议上下文**重新请求 Voice（限次）或降级为**法典+物理拼接的模板叙事**。 |
| **与 M1 关系** | 可与 `Dynamic_Inference` 摘要、`Arbiter_Bias` 已确认令牌组合门控；**不**替代用户主动确认的 Logic Interrupter，而是 **Voice 层的免疫系统**。 |
| **规范落点** | 协议全文见 `docs/V12_BRAIN_FRAMEWORK.md` **§6（M2）**：PSV、`Semantic Auditor`、`REJECT_REASON_CODE`、`AUTO_RETRY_PROMPT`、`[LOGIC_CONFLICT]` 异议块。 |

**设计原则**：校验层输入输出必须是**可机器比对的离散或有序标签**，禁止把整段 Markdown 直接丢给另一 LLM「你觉得矛盾吗」作为唯一依据（可作为辅助，不能作为唯一闸门）。

---

### 3.B 动态置信度补完（Interactive Belief Completion）

| 项目 | 说明 |
|------|------|
| **功能** | 当系统检测到 **关键逻辑点**（如法典中的高敏结构：官杀混杂等——具体清单由规则注册表维护）的 **置信度/稳定度低于阈值**，中枢 **主动**向裁决者发起 **结构化询问**（非自由闲聊优先）。 |
| **演进要求** | 用户回答 **不得**仅作聊天日志；必须经解析写入 **`Arbiter_Bias`**（权重、选项枚举、置信补充字段），并 **触发下一轮物理或法典重算**（在协议允许的参数与侧车范围内）。 |
| **与 M1 关系** | 直接沿用 **Logic Interrupter** 的 `InterruptRequest` / `InterruptAck` 形状；`ack_token` 与 `Arbiter_Bias` 合并策略见 M1 §4。 |
| **规范落点** | 微对话、触发分类、偏置回写与挂起状态机见 `docs/V12_BRAIN_FRAMEWORK.md` **§7（M3）**。 |

---

### 3.C 碎片化断言管理（Fragmented Assertion Sovereignty）

| 项目 | 说明 |
|------|------|
| **功能** | 废弃「单次终判整包生成即真理」的默认模式；改为由系统维护 **断言生长树**（版本化、可挂载父节点、可追溯 evidence 与法典 `pattern_id`）。 |
| **逻辑分工** | **确定性结论**（过/不过门控、是否红线归零、排名头名）由系统从 **法典与 Bone 摘要** 挂载为树节点；**模糊带**（修辞、情境、行为建议的语气）由 **Voice** 在叶节点或标注为 `voice_only` 的边上缝合。 |
| **收益** | 拒稿与差分可定位到**子树**；Diff 对裁决者与审计友好。 |
| **规范落点** | `AssertionNode`、树 patch、`StitchingRequest` / `Summary_Fragment`、剪枝与高亮见 `docs/V12_BRAIN_FRAMEWORK.md` **§8（M4）**。 |

---

## 4. 进化机制（Self-Evolution Loop）

| 项目 | 说明 |
|------|------|
| **目标** | 系统记录 **裁决者习惯**（非模型黑箱），形成可审计的 **逻辑预设** 与 **法典阈值微调建议**。 |
| **输入** | Decision Inbox **历史勾选**、确认的 `ack_token`、归档语义类型分布、`user_intention` 切换模式等（均属于或镜像至 `Arbiter_Bias` / 持久化层）。 |
| **输出（建议态）** | **建议**生成「下一盘默认开启的追问级别」「某类碰撞默认 advisory/blocking」「法典参数微调草案」——须经 **显式发布流程**（人工或配置审批）才能进生产 Manifest，**禁止**静默写回全局法典。 |
| **与三权关系** | 进化回路只产生 **提案**；**Law** 的真源仍是版本化法典与发布流程，**Bone** 的公式仍受宪法与配置治理约束。 |

## 5. 与现有实现的差距（诚实标注）

| 能力 | 当前近似实现 | V12 Inference-Pulse 目标 |
|------|----------------|----------------------------|
| 脉冲感知 | 以请求为边界，无统一 Hub 节拍 | 订阅式状态机 + 事件总线（规格后续模块） |
| Voice 校验 | 弱模式证据锚、空响应兜底 | **Logic Integrity Guard** 语义–物理符号对撞 |
| 用户追问 | Inbox + 意志部分落地 | **Interactive Belief Completion** 强制结构化进 `Arbiter_Bias` + 重算闭环 |
| 断言 | 终判大块 + assertions 列表 | **断言生长树** 与法典节点显式绑定 |
| 进化 | 持久化合并、学习注解片段 | **习惯分析 → 建议 → 审批 → 配置/Manifest** 分阶段闭环 |
