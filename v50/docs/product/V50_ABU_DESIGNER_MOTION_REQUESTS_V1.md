## 下一批：小剧场演员动作

以下提示词按优先级排序。每条只生成一个动作，时长控制在 5 至 10 秒。

### P0 `touch_light_path`

```text
同一只阿布黑色柴犬，红色围巾，角色比例和既有素材完全一致。阿布以三分之四侧身站立，面向右上方，先安静观察一个悬浮的小光点，再向前走一小步，缓慢抬起前爪轻触光点；光点只产生柔和涟漪，不出现法阵、闪电或夸张魔法。阿布的眼神和脑袋始终跟随光点，触碰后停留一秒，再自然收回前爪。固定镜头，完整角色不出画，动作自然连贯，开头和结尾各稳定停留 0.4 秒，6 至 8 秒，无文字、无图标、无水印。
```

用途：开场发现光路、触发六柱展开、用户操作响应。

### P0 `soft_nod`

```text
同一只阿布黑色柴犬，红色围巾，坐姿或稳定站姿，三分之四侧身看向左上方。阿布先专注观察，耳朵轻轻放松，然后克制地缓慢点头一次，露出很轻的确认神情，最后把视线重新放回左上方。不是欢呼，不摇爪，不夸张摆尾，不表达吉凶。固定镜头，完整角色不出画，开头和结尾各稳定停留 0.4 秒，5 至 6 秒，无文字、无图标、无水印。
```

用途：路径重新获得支持、用户确认、阶段判断成立。

### P0 `look_forward`

```text
同一只阿布黑色柴犬，红色围巾，采用侧后方或三分之四背影站姿，和观众一起望向右上方远处。阿布不看镜头卖萌，只轻轻抬头看向远方，围巾和尾巴被微风自然带动，随后稳定停在共同眺望的姿态。动作温暖、安静、有继续前行的感觉，不奔跑、不挥手、不出现文字。固定镜头，完整角色不出画，6 至 8 秒，无图标、无水印。
```

用途：小剧场片尾、“看见命局，也看见自己”。

### P1 `calm_walk_and_notice`

```text
同一只阿布黑色柴犬，红色围巾，从画面左侧平静走入，走三至四小步，在画面中央自然停下；随后耳朵轻动，脑袋转向右上方，像刚刚发现一个值得观察的结构。不要奔跑、跳跃或招手。固定镜头，全身始终可见，脚步稳定不滑动，开头和结束姿态可与其他动作衔接，6 至 8 秒，无文字、无图标、无水印。
```

用途：小剧场走位、从旁白进入 OneCanvas。

### P1 `probe_invite`

```text
同一只阿布黑色柴犬，红色围巾，面向观众但身体略侧。阿布认真倾听后向前轻靠，抬起一只前爪做温和邀请，再依次看向画面左侧和右侧两个空白选择位置，最后回看观众并保持等待。不要生成按钮、文字或答案，不要连续挥手。固定镜头，完整角色不出画，5 至 7 秒，无图标、无水印。
```

用途：Probe、两项选择、邀请用户继续。

### P1 `listen_and_remember`

```text
同一只阿布黑色柴犬，红色围巾，安静坐着，视线朝向画面右侧。阿布先认真倾听，耳朵先后轻动，脑袋略微歪一下，随后缓慢点头并恢复专注坐姿，表现“我听见并记住了”，不要拿纸笔，不要说话，不要夸张微笑。固定镜头，完整角色不出画，5 至 7 秒，无文字、无图标、无水印。
```

用途：用户输入、案例记忆、长期陪伴对话。

## 统一交付规格

```text
时长：4 至 6 秒
源画面：至少 1280 × 720
背景：优先真正透明；普通 MP4 使用纯亮绿或纯亮蓝、稳定无纹理的抠像底，不再优先纯黑底
角色：比例、围巾、颜色和线条保持一致
位置：角色和动作尽量留在 x=130..1030、y=20..700
镜头：固定，不推拉，不抖动
节奏：开头和结尾各停留约 0.3 秒
禁止：水印、右下角图标、文字、边框、随机饰品、角色变形、镜头切换
```

补充：阿布黑色毛发与纯黑背景接近，黑底会损失眼睛、耳缘和毛发细节。若生成工具只能给普通 MP4，请使用均匀亮绿底；背景不得在角色周围产生绿光、阴影或环境反射。

Web 产品导出规格：

```text
静态微动作：640 × 640 或 720 × 720
横向活动动作：960 × 640
WebP quality：92 至 94
透明通道：完整保留
角色脚底锚点：画布高度的 96% 至 97%
```

## 使用原则

- 动画表达产品状态，不表达吉凶。
- 每个动作只有一个主要含义，不混合欢迎、警告和庆祝。
- Abu 的动作由 Journey 状态触发，不由 LLM 自由选择。
- LLM 可以生成 Abu 的一句话，但不能改变动画状态机或命理结论。
