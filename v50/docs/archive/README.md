# V50 Archived Documents

Files below are retained for archaeology, evidence, and decision history. They
are not current architecture or product authority.

## Rules

1. Do not implement new behavior from an archived document.
2. Use `../../CURRENT_ARCHITECTURE.md`, `../../CURRENT_PRODUCT_BASELINE.md`,
   `../../CURRENT_IMPLEMENTATION_ROADMAP.md`, and `../../DECISION_REGISTER.md`
   for current decisions.
3. An archived document may be cited as historical evidence, but a current
   contract must own any revived requirement.
4. Moving a document here does not delete its test or research value.

## Categories

- `architecture/` — superseded architecture audits and former large-cycle roadmaps.
- `execution/` — completed runbooks, benchmark plans, latency experiments, and long-task records.
- `product/` — superseded UI/product proposals and replaced interaction models.
- `proofs/` — completed technical spikes and prototype contracts retained for regression evidence.
