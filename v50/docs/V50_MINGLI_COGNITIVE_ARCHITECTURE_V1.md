# V50 Mingli Cognitive Architecture v1

Status: production architecture authority

## Mission

DeepBazi digitizes the cognitive process of a Mingli practitioner, not merely a
library of conclusions. The LLM is the case-level cognitive reasoner. V50 is its
factual world, tool system, task director, case memory and evidence boundary.

## Authority model

```text
Deterministic Mingli World
  calendar / pillars / ten gods / relations / Ziwei plate / timing material
                         |
                         v
Context Compiler
  minimum sufficient facts / knowledge / tool observations / task boundary
                         |
                         v
Cognitive Orchestrator
  stage order / model route / tool request / context receipt / failure isolation
                         |
                         v
LLM Cognitive Reasoner
  pattern / hypotheses / work path / useful-god logic / domain cognition / probe
                         |
                         v
Hypothesis and Assertion Workspace
  case beliefs / claims / evidence / counter-evidence / unknowns / revisions
                         |
                         v
Abu and Task Canvas
```

The Orchestrator is not another Mingli brain. It may decide what task happens
next, what context is supplied and which model is used. It may not choose a
Mingli hypothesis or author a case judgment.

## Deterministic, cognitive and hybrid modules

### Deterministic authority

- calendar, four pillars, hidden stems and ten-god ledger;
- branch/stem relations, Ziwei placement and timing material;
- graph construction, candidate paths, ablation execution and synthetic mutation;
- evidence IDs, permissions, persistence, privacy and capability boundaries;
- application of an already-declared case-local belief update.

### LLM cognitive authority

- whole-chart attention and pattern discovery;
- competing hypothesis generation and comparison;
- main work path, body/function and conditional useful-god reasoning;
- whole-person, career and wealth causal assertions;
- prior falsifiable predictions and discriminating probe wording;
- explanation, analogy and case-local interpretation of free-form feedback.

### Hybrid authority

- Graph/Path/Role/Ablation produce observations; the LLM decides their meaning.
- Retrieval selects relevant knowledge; the LLM compares applicability and counter-conditions.
- Timing computes activation facts; the LLM forms conditional timing hypotheses.
- Probe Planner selects the epistemic target; the LLM expresses the question;
  the Workspace applies bounded case-local updates.

## Production cognition sequence

```text
Pattern and competing hypotheses
-> Main work path, body/function and useful-god conditions
-> Three falsifiable priors and a discriminating probe
-> Career causal reasoning
-> Wealth causal reasoning
-> Case workspace persistence
```

Each stage receives a stage-specific ContextPack and produces a typed artifact.
No stage receives the entire product problem.

## Required infrastructure

1. `ModelPolicyRouter`: task-to-model and context policy, with no Mingli judgment.
2. `MingliContextCompiler`: stage-specific minimum sufficient world context.
3. `CognitiveOrchestrator`: authorized stage graph and auditable receipts.
4. `CaseCognitiveWorkspace`: hypotheses, assertions, user evidence and revisions.
5. `ProbePlanner`: role/scenario-specific information-gain experiments.

## Probe semantics

```text
Probe Target
-> Information Needed
-> Role/Scenario Projection
-> Question and Options
-> Response Evidence
-> Case Belief Update
```

A probe may update only the current case. It may not mutate chart facts, global
theory, model policy, runtime rules or training weights.

| Mode | Probe job |
|---|---|
| Guest | one low-friction recognition discriminator |
| Member | reality and decision-relevant hypothesis discrimination |
| Practitioner | professional differential diagnosis with visible update logic |
| Research | falsification, counter-evidence and anomaly capture |

## Validation and training

The system distinguishes four activities:

```text
Tool Validation
Agent Evaluation
Evidence Collection
Model Training
```

Synthetic charts remain the primary evidence for structural invariants and
metamorphic behavior. They do not provide canned reading text. Model training is
not permitted until expert-reviewed cognitive records contain the world context,
competing hypotheses, selected path, counter-evidence and case outcome.

## Retired authority

The following may remain as historical or research artifacts, but cannot author
production cognition:

- deterministic `BrainVerdict`;
- fixed Mechanism-to-domain mappings;
- Theme/Probability/Decision template readings;
- Product Mode engines;
- expression adapters that expand shallow deterministic semantics.

## Non-negotiable invariant

> The system computes facts, supplies tools, organizes attention and constrains
> updates. The LLM understands the chart. The case workspace remembers what was
> believed and why. No other layer silently invents a Mingli verdict.
